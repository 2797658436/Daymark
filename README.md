# Daymark

Daymark 是一个本地优先的 Windows 计划管理工具。当前仓库已交付阶段 2 正式 21 天候选版，并完成阶段 3 M5：在默认时段折叠和连续缩放基础上，日／周时间轴已支持实时拖拽预览、插入后移、同时安排、并行汇总与空白时段框选。

## 当前已实现

- React、TypeScript、Vite、Tailwind CSS 与 Tauri 2 的正式桌面工程，可生成 NSIS 安装包。
- SQLite `schema_version` v5 与五步事务迁移；稳定文本 ID、外键关系和九类核心对象。
- Project、Task、ExecutionSession、ExecutionRecord、ProgressEvent、TimeBlock、RecurringHabit、HabitOccurrence 与挽救提示事实。
- 今日页、活动任务池（含"需要关注"折叠区）、普通项目、文本课程导入、B 站链接导入 Beta，以及日／周／月三视图日历。
- 仅标题快速创建；任务可补充项目、截止日期、预计耗时、单次投入、优先级，并由用户手动调整完成度。
- 从任务池拖入日历、移动或缩放执行时段、任务卡铅笔按钮精确编辑日期与起止时间、拖回任务池取消安排，以及 Ctrl+Z 撤销；可见磁铁按钮显示当前吸附状态，`Alt` 在拖拽／拉长时临时反转吸附。拖动期间持续显示精确起止时间与落点，卡片边缘提供“插入并后移”，中央悬停约 500ms 提供“同时安排”；批量让位使用一次原子写入和整体撤销。并行 2–3 项等宽并排，4 项以上显示“另外 N 项”并可原位展开。空白悬停显示时间，单击或纵向框选后打开“新建任务／从任务池安排／时间块”气泡。时间轴仍支持指针锚点连续缩放、卡片信息自适应和默认时段临时展开。
- 自动排程 Lite：在未来 7 天默认时段空档生成确定性草案，避开已有安排与时间块，确认后原子写入并可撤销。
- 轻量时间块：日历可创建／删除只含标题、日期与起止时间的占用时段。
- 基础重复习惯：每天／工作日／每周选日，独立发生项进入执行闭环，未完成不累积欠账。
- 可选的开始／结束本次、实际投入修正和本次小结；错过后的中性挽救提示（现在开始／延后 10 分钟／重新选择时间／本次跳过）只出现一次。
- 简单最近 7 天回顾：汇总实际投入、进度、待续与未执行／跳过事实，不评分。
- 执行提醒、启动摘要、关闭到托盘、托盘恢复窗口与退出。
- 每日备份按日期去重并保留最近 7 份；原子手动备份、结构校验、恢复前备份和数据／偏好协调回滚；数据页持续显示自动备份错误。
- Tauri Store 保存外观、动态效果、100%–200% 界面缩放、最后页面、日历视图／日视图显示模式／各视图日期锚点／缩放状态、计划／实际叠加状态及工具栏入口、提醒、默认时段（可为空或多个、含星期）与自动排程偏好。
- 扁平暖杏浅／深色界面、可收起任务池、960–1199px 覆盖面板、独立焦点环和基础无障碍。

当前已知边界：开机自启尚未实现；提醒由运行中的前端检查并通过桌面通知，Windows 通知本身没有任务级点击回调，但提醒后通过托盘恢复会打开对应日历时段，应用内今日页和 `daymark-open-session` 事件也支持目标显露；阶段 3 M6 的周视图全天区、月摘要与键盘导航尚未实现；独立截止任务页、完整日／周／月回顾、复杂重复规则、AI 规划和高级布局自定义仍属后续阶段。更完整的目标边界见[阶段规格](docs/specs/0003-phase-3-calendar-experience.md)和[中心实现指南](docs/PROJECT-GUIDE.md)。

## 开发与验证

需要 Node.js、Rust stable、Windows C++ 构建工具和 WebView2。

```powershell
npm install
npm run test
npm run test:e2e
npm run test:native
npm run build
npm run check
```

运行桌面开发版：

```powershell
npm run tauri dev
```

生成 Windows NSIS 安装包：

```powershell
npm run tauri build
```
