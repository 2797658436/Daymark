## 交付范围

### 1. 打包与可追溯安装包

- **必须套 MSVC 环境**：`scripts/with-msvc-env.sh npm run tauri build`。
  裸跑会让 rustc（`x86_64-pc-windows-msvc`）按名字命中 Git Bash 自带的 GNU `link.exe`，报 `link: missing operand` 之类**与真实原因无关**的错误。release 依赖已缓存时约 2 分 20 秒。
- 产物：`src-tauri/target/release/bundle/nsis/Daymark_<版本>_x64-setup.exe`；裸可执行文件在 `src-tauri/target/release/daymark.exe`。仓库惯例是复制一份到 `artifacts/`（该目录已 gitignored）交给用户实测。
- **记录 SHA256 与安装包路径**（规格 §12 的交付记录要求）。
- ⚠️ `artifacts/` 里现有 `Daymark_0.1.0_x64-setup.exe`（2026-10-15 20:51）—— 那是**上一份已验证安装包**，也就是**回退目标**，**不要覆盖它**。

### 2. 隔离环境验收（AC17／AC18）

规格 §12 写得很硬：**「不能在唯一的个人数据库上覆盖恢复来获取测试证据」**。必须在**独立 Windows 账户**或**明确隔离的数据环境**里完成：

- 旧 v7 备份恢复；
- **缺少新偏好的恢复**（旧设置文件没有 P4-05／P4-07／P4-08 新增的字段）；
- 损坏备份拒绝；
- 恢复偏好失败回滚；
- **实际托盘与提醒**（AC17）：关闭驻留托盘、显式退出、提醒后恢复、目标不存在时的回退；
- **升级后重新启动**（AC18）：干净安装、覆盖升级。

**动手前先决定并写清怎么隔离**（新建 Windows 用户账户 / 把 `APPDATA` 指向临时目录 / 单独的数据目录）。这是本包最容易糊弄过去的一环 —— 不要用「跑了一遍没事」代替隔离证据。

### 3. 回退验证

规格 §12：schema 不变，回退使用**上一份已验证安装包**；先手动备份当前数据与设置，**退出托盘进程**，再替换版本。旧版本可能忽略新增偏好，但**不应改变核心数据**。

**发布前必须实测往返兼容，不能仅凭 schema 相同就宣布安全。**

### 4. 真机复测性能

**真机复测至少跑两次（一次机器空闲、一次带负载）**，不要只看一次读数。命令：`node scripts/measure-perf.mjs`（生产构建 + 真实 Chromium，结果落 `output/`）。

## 已定案：P4-09 §9 的三条（2026-10-16 用户确认，论证见 `phase-4-open-decisions.md` §7）

- **① sequential（最坏情况）口径不算进预算** —— 保持 **isolated 稳态判据**。规格 §8 的措辞是「预热后 20 次」，规格没有定义页面复用；而且月回顾**纯计算**只要 6.6–8.4ms，差额全在渲染与堆压力，按 sequential 判会把「堆里有前序 DOM 残骸时的 GC 变慢」误记成「回顾页算得慢」，修也会修错地方。
  **但要写进已知边界与发布说明**：sequential 下月回顾 P95 117.4ms 超 100ms（规格 §12：S2 记录影响、替代路径和后续任务）。
- **② 日历网格 ARIA 缺陷不并入本包** —— 单开 **P4-11**（提示词见 `docs/reports/phase-4-p4-11-kickoff-prompt.md`）。**本包不要去改周／月网格**（验收包里改产品代码，会让已验证安装包对应的代码在发布前又变一次，整套隔离验收与视觉证据都要重跑）。
  **但必须做两件事**：把 S2 写进 PROJECT-GUIDE 的已知边界；**在发布说明里写明这条已知无障碍缺陷** —— 受影响的是屏幕阅读器读不出「第几行第几列」，**视觉与键盘用户不受影响**（方向键、PageUp／PageDown、Enter 语义照常），且单元格 `aria-label` 已含完整日期时间。
- **③ 关键证据已入库** —— P4-09 的 14 张截图与 7 个性能 JSON 已搬到 `docs/reports/phase-4-p4-09-implementation/`（`output/` 是 gitignored 的，报告引用那里就是死链）。**本包的交付记录（截图、安装包路径与 SHA256）照同样做法入库**，不要只留在 `output/`。
- **S3 1200×200% 下截止页筛选复选框第一次鼠标点击落空**（根因：焦点态改变盒子尺寸，`getBoundingClientRect().y` 从 269.2 → 301.7，于是 `mouseup`／`click` 落到祖先容器上；只在那一格复现，键盘路径正常）—— **本包不修，写进已知边界**，与 ② 同属「记录影响 + 后续任务」。
