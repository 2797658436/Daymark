## 0. 准备（约 1 分钟）

### 0.1 把应用跑起来

```powershell
npm run dev
```

然后浏览器打开 **http://127.0.0.1:1420**。

> 为什么用浏览器版：桌面版的设置与数据存在 Tauri Store 文件里，灌样本很麻烦；浏览器版存在 `localStorage`，**界面完全一样**。看口径用浏览器版就够，不用等 `tauri dev` 编译。

1. 按 **F12** → 切到 **Console**
2. 打开 `docs/reports/phase-4-walkthrough-seed.js`，**整份**粘进 Console → 回车
3. 按 **F5** 刷新

页面会直接落在「截止事项」页。想清空重来：Console 里跑 `localStorage.clear()` 再 F5。

## 2. D1 截止页要不要常驻任务池

**点法**：

1. 左侧点 **「截止事项」**（页面已在，再点一次确认）
2. 看**右侧**有没有任务池
3. 把浏览器窗口拖窄到 **1200 像素以内**（大约半屏），再看右侧
4. 对照：左侧点 **「今日」**，同样看右侧

**你会看到**：

- 「截止事项」页：**右侧没有任务池**，无论窗口宽窄都没有（窄窗口下连「打开任务池」的小按钮都没有）。页面就是「一排筛选 + 分组列表」。
- 「今日」页：**右侧有任务池**（能创建任务、能拖到日历）。窗口拖窄后它会变成一个从右边滑出、盖住内容的浮层。

**另一条路会变成**：截止页右侧也长出那一栏（320px）。但**它拖不动** —— 截止页没有时间轴，「拖到哪」没有语义；要能拖就得重新设计成三栏并定义落点，规格里没写这件事。

**要你回一句**：截止页要不要这一栏？（我的建议：**不加**。截止页的定位是「集中查看 + 跳转」，要安排某条任务，每行右边就有「安排」按钮。）

## 3. D2 搜索关键字要不要也匹配项目名

**点法**：

1. 左侧点 **「截止事项」**
2. 找到筛选区第二行左边的 **「关键字」** 输入框（灰色提示文字是「搜索标题」）
3. 输入 **`Rust`**，停一秒看列表

**你会看到**：列表变空，显示「**筛选没有匹配**」+ 一个「清除筛选」按钮。

> 为什么：样本里项目叫 `Rust 入门`，但它下面唯一的任务叫 `起步` —— 任务标题里没有 "Rust"，所以现在搜不到。

**另一条路会变成**：列表里会出现 `起步` 这一行。但你**看不出它为什么出现**（标题里根本没有你搜的词），得额外加文案，比如行尾标一句「所属项目命中」。

**要你回一句**：搜任务的时候要不要顺带把项目的任务捞出来？（我的建议：**不加**，保持「搜什么就出什么」；将来真需要，改一处判断即可。）

## 5. D5 点过「回到现在」之后，下次打开要不要还停在「现在」

**点法**：

1. 左侧点 **「日历」**
2. 用**鼠标滚轮**把时间轴滚到别处（比如滚到中午）
3. 记住屏幕中央大概是几点
4. 按 **F5** 刷新
5. 看屏幕中央**是不是回到了你刚才滚到的位置**
6. 点右下角出现的 **「回到现在」** 按钮（只有你滚走之后它才出现）
7. 再按一次 **F5**
8. 看这次落在哪

**你会看到**：

- 第 5 步：**回到了你滚到的位置** —— 手动滚动被记住了。
- 第 8 步：**落在「现在」** —— 也就是说「回到现在」这个动作**本身也被记住了**，下次打开仍然停在现在。

**另一条路会变成**：第 8 步会回到第 3 步那个位置，而不是「现在」。

**要你回一句**：点完「回到现在」，下次打开是停在「现在」，还是回到你上次手动滚到的地方？（我的建议：**停在现在**。这是你自己点的定位，记住它更符合直觉。）

## 6. D4 日历里「7 天内截止」的判定 —— 不用点界面，但一条命令就能证明

**为什么点不出来**：这个错**只在秋季夏令时回拨那一周显形**。本机时区是 UTC+8，没有夏令时，所以你在界面上永远看不到它出错 —— 样本里那条 `正好七天后的任务` 显示是正确的。

**但它可以证明。** 把下面这一行粘进 PowerShell 或 Git Bash 回车：

```powershell
node -e "process.env.TZ='America/New_York'; const a=new Date('2026-10-25T12:00:00'), b=new Date('2026-11-01T12:00:00'); console.log('两天偏移:', a.getTimezoneOffset(), b.getTimezoneOffset()); console.log('相差毫秒:', b-a, '  7天应是:', 7*86400000); console.log('现在会判成:', (b-a)<=7*86400000 ? '7 天内截止' : '未来截止');"
```

我实测的输出：

```
两天偏移: 240 300
相差毫秒: 608400000   7天应是: 604800000
现在会判成: 未来截止
```

`2026-11-01` 是北美夏令时结束那天，那一天是 **25 小时**。`2026-10-25` 到 `2026-11-01` 正好 **7 个日历日**，却因为多出 1 小时被算成 8 天 → 显示「未来截止」。**应该是「7 天内截止」。**

> 一个坑（我一开始也踩了）：`TZ=America/New_York node ...` 这种**环境变量前缀在这台机器上无效**（被沙箱剥掉，`process.env.TZ` 仍是 `undefined`）。必须在 **Node 进程内部**赋值才生效 —— 上面那行就是这么写的。

**要你回一句**：改不改？（我的建议：**改**。换成按日历日算，再加一条自动检查防止有人改回去。它只影响日历标记上「7 天内截止 / 未来截止」这几个字和颜色，不动任何数据。）
