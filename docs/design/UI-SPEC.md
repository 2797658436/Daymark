# Daymark UI 规范

## 视觉方向

- 默认视觉为温柔沉浸型：舒缓、亲近，降低打开计划工具时的压力感。
- 主题只替换颜色体系；页面结构、组件形状、功能与信息层级保持一致。
- 动效应精致而克制，用于解释状态变化和增强拖拽反馈，不以炫技为目的。

## 主题

- 第一版提供四套颜色主题：默认“暖杏”（奶油底色、杏色强调、低饱和绿色点缀）、安静专注的“雾蓝”、柔和夜间氛围的“暮紫”和干扰最少的“黑白”。
- 所有界面颜色通过语义化主题变量提供，避免组件内写死颜色。
- 颜色主题与外观模式彼此独立；每套主题均支持浅色、深色和跟随系统，切换时不改变布局、组件形状或交互。

## 视觉令牌基线

- 字体使用 Windows 本地栈 `"Segoe UI Variable Text", "Microsoft YaHei UI", system-ui, sans-serif`，不要求下载网络字体；时间、时长、百分比和表格数字启用等宽数字。字重只使用 400、500、600，普通正文不以全粗体制造压力。
- 字号与行高基线为 `12/16`（辅助与元信息）、`13/18`（紧凑列表）、`14/22`（正文与控件）、`16/24`（分区标题）、`20/28`（页面标题）、`28/36`（仅“现在”等单一主焦点）。正文默认 14px，任何密度都不把可读文字缩到 12px 以下；信息层级优先通过间距和字重而非不断放大区分。
- 间距采用 4px 网格，令牌为 `2, 4, 8, 12, 16, 20, 24, 32, 40, 48px`。紧凑／标准／详细密度分别以约 `8／12／16px` 作为卡片主要内边距，以 `6／8／12px` 作为同组间距；密度只改变留白与展示字段，不改变页面结构、状态语义或约 44px 的命中区。
- 圆角令牌为 `6px`（小标签／输入内部）、`10px`（按钮／输入框）、`14px`（卡片／气泡）、`18px`（面板／大型非模态层）和 `999px`（胶囊标签）。同一组件在四主题间保持相同圆角，避免主题切换产生不同产品性格。
- 普通分隔线与卡片边框为 1px，选中、当前安排和拖拽落点可使用 2px；键盘焦点使用独立的 2px 外环及 2px 间隔，能够与选中状态同时出现。分类继续只用窄色条或极淡底色；警告、错误、完成和当前状态必须同时配有文字或图标，禁用态使用满足对比度的专用语义色而不是整体降低透明度。
- 阴影只使用三级固定几何：`低层 0 1px 2px`、`浮层 0 6px 18px`、`模态／拖拽 0 16px 40px`，透明度由各主题的语义阴影色提供。静止卡片默认使用边框而非阴影；悬停最多进入低层，气泡与菜单使用浮层，模态和正在拖拽的卡片使用最高层，不叠加多重发光。
- 图标尺寸基线为 16px（行内状态）、18px（普通控件）、20px（导航）和 24px（少量主操作），描边风格和线宽保持一致。图标按钮继续使用约 44px 命中区并提供文字提示；同一图标不能在不同页面承担相反含义。
- 动效时长令牌为 `100ms`（按下、颜色与小提示）、`160ms`（悬停、气泡进入）、`220ms`（卡片让位、面板与布局过渡）、`320ms`（一次性完成反馈）；标准缓动为 `cubic-bezier(0.2, 0, 0, 1)`，退出为 `cubic-bezier(0.4, 0, 1, 1)`。拖拽回位允许使用无明显反弹的临界阻尼效果，连续列表不得逐项错峰造成等待；减少动态模式仍执行既定的不超过约 100ms 淡变或即时切换。
- 交互状态顺序统一为默认、悬停、按下、选中、键盘焦点、禁用；悬停只轻微改变表面或边框，按下不造成布局位移，选中使用强调边框与淡底，焦点使用独立外环。当前安排可增加克制光晕，实际执行再配合实色记录层和文字标签；完成反馈结束后回到稳定静态状态，不持续闪烁、呼吸或庆祝。

## 主窗口结构

- 左侧为可收起的主导航，设置入口固定在左下角。
- 主导航页面采用固定顺序：`今日`、`日历`、`截止任务`、`项目`、`回顾`。今日与日历属于高频行动区；截止任务与项目属于计划整理区并以细分隔线区分；回顾置于其后。第一版不允许重排或隐藏这些页面入口，避免不同布局下失去稳定位置。
- 导航图标使用单一、直接的语义：今日使用房屋，日历使用日历页，截止任务使用旗帜，项目使用文件夹，回顾使用趋势图；底部的自定义界面使用画笔，设置使用齿轮。图标不随主题改变含义，不用只有颜色差异的近似图标表示不同页面。
- 展开状态同时显示图标与完整中文名称；收起状态保留 64px 图标栏，并在鼠标悬停或键盘聚焦时显示名称提示。截止任务等数量徽标在两种状态下均保留，但只表达事实数量，不用跳动或持续闪烁制造压力。
- 当前页面使用固定的圆角底色、左侧强调条和较高字重共同标记，并为辅助技术设置 `aria-current="page"`；不能只依靠主题色，也不通过放大图标或移动位置造成导航跳动。
- 可用宽度不小于 1200px 时，主导航初始展开，并记住用户手动展开或收起的偏好；窗口缩至 1200px 以下时临时收成图标栏，重新变宽后恢复用户原偏好，自动收起不会覆盖该偏好。
- Daymark 的目标最小可用窗口为 960×640 逻辑像素；在 960–1199px 宽度下保持 64px 导航栏，右侧任务池或详情改为由中央区域边缘按钮唤出的覆盖面板，打开时不永久挤压日历时间轴。点击遮罩、按 `Esc` 或完成选择后可以收起覆盖面板，未保存编辑时先给出就地保留／放弃选择。
- 桌面应用不设计独立移动端导航；若显示器或系统缩放使可用工作区小于目标最小尺寸，屏幕可用范围优先，继续采用图标导航、覆盖面板和纵向滚动，不能把窗口边缘强制放到屏幕外。恢复的窗口位置与尺寸始终约束在当前显示器工作区内。
- 中央为当前页面的主要工作区，日历与拖拽操作应获得最大的可用空间。
- 日历页面的右侧面板默认显示任务池，任务可从这里直接拖入中央时间轴。
- 选择任务后，右侧面板切换为任务详情，并通过返回操作回到任务池；整个面板可以收起，收起后保留重新打开任务池的入口。
- 左侧导航底部在设置旁提供固定的“自定义界面”入口；展开导航时显示文字，收起时保留画笔图标和提示，该入口本身不可隐藏。
- 点击后进入全局界面编辑模式：可调整区域显示虚线边框、拖拽把手及显示／隐藏控制，用户可以在今日、日历和项目等页面间切换并连续编辑。
- 编辑模式只允许：调整右侧任务池／详情面板的默认展开状态及 300–480px 宽度；在同一页面预设槽位内重排标记为可选的摘要、已完成内容或近期记录模块；调整各页面工具栏中非核心按钮的顺序和常显／隐藏。模块不能跨页面移动，中央工作区、时间轴、卡片列表和导航不支持自由缩放或任意浮动。
- 主导航页面及顺序、设置与“自定义界面”入口、顶部“保存并退出／取消”、今日页“现在”模块、日历时间网格与视图切换、任务池列表及“新建任务”、项目任务列表，以及每个页面的“更多”入口不可隐藏。截止与里程碑等事实标记也不因布局自定义被隐藏。
- 隐藏工具栏按钮前先检查替代入口：普通安全动作必须保留在该页“更多”菜单，并可按既定边界出现在命令面板；删除、恢复等危险动作只保留在相应详情或“更多”菜单中，不能为了替代隐藏按钮而加入命令面板。不存在替代入口的按钮不提供隐藏控制。
- 编辑中的变化先作为跨页面草案存在，顶部固定显示“预览”“恢复当前页面默认”“取消”和“保存并退出”。预览隐藏编辑轮廓并允许导航、滚动和悬停检查，但禁用会修改任务数据的操作；取消恢复进入编辑模式前的完整布局，存在草案时按 `Esc` 使用锚定小气泡确认放弃。
- “恢复当前页面默认”只修改草案，因此可通过取消撤回；“恢复全部界面默认”放在顶部更多菜单，先显示受影响页面数，提交后仍提供一次撤销。恢复布局只影响可见性、顺序和面板尺寸，不改变主题、任务数据或普通功能设置。
- 每次“保存并退出”生成一个带时间的本地布局版本，保留最近 5 个和出厂默认；用户可在自定义入口的“布局版本”中预览并恢复，恢复也先成为草案而非立即覆盖。应用升级遇到失效模块时忽略未知项、补回新增的必需入口，并保留升级前最后可用版本作为恢复点。
- 低于 1200px 时继续使用既定的导航图标栏和右侧覆盖面板，工具栏按钮按用户顺序依次进入“更多”；这些自动退化不写入布局版本。重新回到宽窗口后恢复已保存的面板宽度、展开状态和按钮常显设置，第一版不维护独立的宽／窄两套自定义布局。

## 无障碍、缩放与高密度数据

- 全页默认焦点顺序为主导航、页面标题与工具栏、中央主要内容、右侧任务池／详情、当前临时层；提供“跳到主要内容”和“跳到任务池”。打开详情、气泡或模态后焦点进入其标题或首个有效控件，关闭后返回原触发位置；模态限制焦点，非模态气泡允许 `Esc` 返回，不制造键盘陷阱。
- 使用 `nav`、`main`、`complementary`、标题层级、列表／列表项和网格等原生语义；日历格暴露日期、起止时间、标题与状态，进度条暴露名称、当前百分比和可调整状态。拖拽的拾起、合法落点、放置和取消通过礼貌级实时区域播报，并为拖拽操作保留现有键盘移动／编辑替代路径。
- 四套主题的普通文字至少达到 4.5:1，对大字、图标、控件边界和焦点指示至少达到 3:1；焦点环在所有主题中保持可见。状态继续同时使用文字、图标或边框，不以颜色、动画或悬停作为唯一信息来源；回顾图表保留文字表格或列表入口。
- 界面遵循 Windows 系统缩放，并支持 100%–200% 的应用内界面缩放；高缩放时优先重排、换行、覆盖面板和纵向滚动，核心操作不能被裁切。日历时间轴缩放继续与界面缩放分离；所有可见控件的实际命中区至少约 44×44px，紧凑图标可视觉更小但保留透明命中区。
- 动效默认跟随 `prefers-reduced-motion`，并在外观设置中提供“跟随系统／减少／完整”覆盖项。减少动态时关闭弹簧回弹、位移让位、脉冲和光晕，改用不超过约 100ms 的淡入淡出或即时状态变化；拖拽预览、当前时间和保存结果仍保持可辨，不以动画停止功能反馈。
- 列表超过约 200 个可见候选项时建议启用虚拟化，课程分 P、历史和搜索“查看全部”超过约 100 行时可更早启用；阈值由性能测试调整。虚拟化以稳定对象 ID 和测量尺寸缓存保持选中项、键盘焦点与滚动锚点，筛选、插入或刷新列表顶部时不能让用户无故跳回开头。
- 连续日视图只渲染当前可见日期和前后缓冲区，并在滚动时回收远处节点；缓冲建议至少覆盖前一天、当天、后一天和一个视口。缩放、跨日加载和补入历史时保持指针时间或首个可见任务为锚点，固定日期头和“回到现在”始终可用。
- 预计超过约 300ms 的加载显示骨架、阶段或行数进度而不遮住已有可用内容；超过约 1 秒且能够安全中止的读取、筛选或导入显示取消。取消后保留上一次稳定结果、查询和滚动位置；数据库提交与恢复替换等不可安全取消阶段继续沿用明确阶段说明，不伪造百分比。
- 屏幕阅读播报、进度刷新和执行计时使用节制频率：只播报用户触发或状态真正改变的结果，不逐秒播报计时。大量任务加载完成时播报结果数量，错误使用更高优先级且只播报一次，避免防拖延工具本身造成持续干扰。

## 任务卡交互

- 任务池保存并展示所有未完成且未暂停的活动任务；任务被安排进日历后仍留在任务池，因为一个任务可以对应多次执行时段。
- 已有日历安排的任务卡显示下一次安排和未来执行时段总数，例如“下次：今晚 19:30 · 未来共 2 次”；任务只有一个对象，不因多次安排而在任务池中生成副本。
- 从任务池再次拖动任务到日历时新增一次执行时段；拖动日历中的执行卡片时只移动已有的该次执行时段，两种来源使用不同的拖拽语义。
- 任务池提供“全部／尚未安排／已有安排”筛选；已完成和已暂停任务不进入默认活动任务池，而在各自分组中查看。
- 任务池顶部固定可折叠的“需要关注”区域，收纳已逾期及未来 7 天内截止的任务并按截止日期排列；这些任务不在下方普通任务区重复出现。
- 任务和重复习惯支持两种置顶方式：“固定置顶”始终保留在置顶区域，直到用户手动取消；“安排前置顶”只在缺少对应未来执行时段时显示，安排后自动退出置顶区域。
- 对每日重复习惯，“安排前置顶”按每个日期的发生项独立判断：当天尚未安排时置顶，安排后当天隐藏，取消该次安排后重新出现；提前安排好的未来日期不会在对应日期重复要求用户处理。
- “安排前置顶”退出的只是置顶区域，任务仍可在“全部任务／重复习惯”中找到；安排未执行时沿用“待回顾”流程，不静默当作完成，也不立即重新置顶制造重复入口。
- 每日重复习惯的发生项未完成时，默认只在原日期留下未推进或待回顾记录；下一天生成自己的发生状态，不自动把昨日时长叠加到今天。
- 未完成的重复习惯发生项提供“补到今天”操作，供用户主动增加一次补做时段；重复规则可选择“未完成则顺延一次”，但活动欠项最多保留一份，连续错过不会生成无限堆积的相同卡片。
- 与重复习惯关联的课程任务或长期任务完成度持续保留，新的日期发生项可以从原进度继续，不因昨日未完成而重置任务进度。
- 普通任务区默认不分组，分类通过“全部／学习／工作／生活”等筛选切换；用户可改为“按分类”或“按项目”分组，各分组可以独立折叠，并记住上次选择。
- 任务池排序提供“截止日期（默认）／优先级／自定义顺序”；只有在自定义顺序下，任务池内部拖动才改变持久顺序。其他排序方式中的拖拽保持排入日历的语义，避免排序与排程混淆。
- 单击任务卡只选中任务，显示柔和描边和快捷操作，不自动打开详情。
- 双击任务卡在右侧面板打开任务详情并允许编辑；键盘选中后按 `Enter` 执行相同行为。
- 任务池工具栏提供可见的“多选”按钮；进入多选模式后任务卡显示选择控件，单击卡片用于增减选择，顶部切换为含已选数量、全选、取消全选、批量编辑和退出的操作栏。
- “全选”只选择当前筛选结果并显示数量，不包含被过滤、已完成或已暂停等当前范围之外的任务；项目内提供范围明确的“全选此项目”。
- `Ctrl + 单击` 和 `Shift + 单击` 作为多选的加速方式而非唯一入口，`Esc` 退出多选或清除选择。
- 多个已选任务拖动时显示叠放卡片和数量，放入日历后按任务池当前顺序连续排入；无单次时长的任务使用全局默认单次投入时长，并沿用跨时段预览与确认。
- 批量拖入成功后，选中状态转移到新生成的日历卡片，便于继续整体移动、顺延或批量调整；点击空白或无关区域、切换页面或按 `Esc` 后取消选中。
- 批量操作栏及其控件不会在操作提交前清空当前选择；结果提示可提供“完成”以主动结束多选。
- 日历中有多张卡片被选中时，拖动其中任意一张卡片的主体会移动整组，并保持各卡片原有的日期差、先后顺序和时间间隔。
- 拖动某张已选卡片的时长边缘时只调整该执行时段，不联动改变其他已选卡片的时长；需要统一时长时，使用批量编辑中的“单次投入时长”。
- 整组移动若跨越默认时段或日期，拖动预览应完整显示每张卡片的新位置、受影响数量及越界范围，并沿用跨时段确认和整组撤销规则。
- 批量编辑支持分类、所属项目、暂停和删除等共同字段，不要求逐项进入详情。
- 任务卡的非交互空白区域均可开始拖拽，不要求用户精准抓住独立把手；指针移动超过约 5px 后才进入拖拽状态，以区分普通点击。
- 进度条、按钮、输入框和文字链接等交互区域只执行自身操作，不触发卡片拖拽。
- 双击不打开独立页面或模态窗口，避免打断当前日历或任务池上下文。

## 详情编辑与确认层级

- 右侧详情面板不设置独立的整体编辑模式；标题、分类、日期和耗时等字段点击后原地编辑。
- 原地编辑使用 `Enter` 或失去焦点保存，使用 `Esc` 放弃本次修改；保存后显示轻量状态反馈，并提供短时撤销入口。
- 任务详情顶部固定显示返回任务池、任务标题、当前状态和“更多”菜单；标题下方只保留与当前状态有关的主操作。内容依次为“推进情况”“基本信息”“未来安排”“耗时与排程”“历史记录”和“更多操作”；前三项默认展开，后三项默认折叠并记住用户之后的展开状态。
- “推进情况”包含手动完成度、今日增加量、今日目标进度和只读累计投入；“基本信息”按名称、分类、所属项目、截止日期、优先级排列；“未来安排”显示下一时段、未来总数与最近三项，并提供新增和查看全部。项目名称可跳转，但子任务只在项目详情管理。
- “耗时与排程”按预计耗时、单次投入时长、需要连续时段和置顶方式排列；媒体时长、来源链接和建议耗时仅在存在时只读显示，建议必须显式采用。“历史记录”按日期倒序展示执行、进度、投入、完成／恢复与顺延摘要，点击后在原面板展开已有补填／修正入口和字段快照。
- “更多操作”置底并包含暂停／继续、基于此重新开始和删除。切换任务或关闭面板时，已提交字段保持保存；无效且未提交的字段在原处要求“继续修改／放弃此次修改”，危险操作继续沿用既定确认层级。
- 普通危险操作使用锚定在触发按钮附近的小型确认气泡，不用居中模态弹窗打断上下文。
- 删除整个项目等影响范围较大的操作使用模态确认，明确展示受影响的任务和历史记录数量。
- 删除任务或项目时，用户可以保留由执行时段、进度变化、投入时间、完成与顺延结果及必要字段快照组成的历史记录，也可以一并彻底删除。
- 设置中提供“每次询问（默认）”“始终保留历史”和“始终全部删除”三种删除记录策略；前两者不会把保留的历史对象继续显示在当前任务池或排程中。
- 任务和项目提供“暂停／继续”，在同一对象上保留进度、投入时间、子任务和历史记录，继续后允许修改未来安排。
- 暂停的任务和项目进入独立的“已暂停”分组；其未来执行时段从活动日历隐藏并停止执行提醒，但作为“暂停前计划”保留，过去的日程与历史不变。
- 暂停期间项目截止日期和里程碑提醒默认继续，并在通知中标明项目当前已暂停；暂停确认气泡提供“同时暂停目标提醒”选项供用户主动静音。
- 点击“继续”时先展示恢复预览；默认按照暂停天数整体后移未来执行时段，再将计划放回活动日历。
- 项目截止日期和里程碑日期不会因暂停或继续而静默改变；恢复预览提供“同时顺延截止日期和里程碑”选项，显示移动前后日期，只有用户明确选择后才按相同自然日数后移。
- 当前对象和保留的历史记录提供“基于此重新开始”操作，打开对应的新建界面并预填可复用信息与任务结构；它创建新对象，不恢复旧进度、旧投入时间、旧执行记录或旧完成状态。
- 任务池卡片默认使用“标准”密度：第一行以任务标题为视觉主体，右侧显示截止状态；第二行弱化显示分类、所属项目或课程分 P 信息；随后显示手动任务进度、百分比与“今日 +N%”；底部按需显示下次安排和快捷操作。
- 卡片左侧使用窄分类色条区分学习、工作、生活等类别，不使用高饱和颜色填满整张卡片；没有填写的预计耗时、项目等字段不保留空占位。
- 任务池提供“紧凑／标准／详细”三种卡片密度并记住用户选择：紧凑保留标题、截止状态和细进度条；标准显示主要上下文和下次安排；详细增加已投入时间、预计耗时、媒体时长等已有信息。
- 选中卡片不改变自身高度，避免任务列表跳动；默认常显“安排”，开始、暂停和更多等快捷按钮可在悬停或键盘选中时出现，并受“自定义界面”的常显／隐藏设置控制。
- 截止信息默认以相对日期显示，例如“还有 6 天”“明天截止”；单击该标签在相对日期与实际日期（例如 `2026.7.30`）之间切换，再次单击恢复。该显示偏好在任务池中统一生效并记住，不改变真实截止日期。

## 日历视图

- 日历默认进入周视图，用于观察一周容量并在日期之间拖拽任务。
- 月视图用于回顾已经完成的事项，并显示任务截止日等重要日期，不承载精细的小时排程。
- 日视图使用可跨越日期边界的连续时间轴；向上进入前一天，向下进入下一天，并以固定日期标题、日期分隔线和“回到今天”按钮防止迷失。
- 日视图提供“默认时段”和“全天”两种显示模式。默认时段模式展开用户配置的多个默认时段，将其他时间折叠为带任务数量提示的间隔条；全天模式完整显示所有时间。
- 用户可以设置默认打开的显示模式，界面也应记住最近一次选择。
- 折叠的非默认时段始终显示其起止时间与其中的安排数量，例如“10:00–18:00 · 2 项安排”；点击折叠条可临时展开，再次点击可收起。
- 拖动任务悬停在折叠条约半秒时自动展开对应时段，以便精确放置；拖离且尚未提交时恢复原状态，成功放置后保留临时展开以展示结果。
- 当前时间位于折叠区时，日视图与今日时间线自动展开当前时间附近约两小时的窗口，确保当前时间线与当前安排可见；其余非默认时段继续折叠。
- 从通知、搜索结果或其他页面跳转到折叠区内的安排时，自动临时展开目标时段并高亮对应卡片。
- 临时展开状态只属于当前浏览过程，不修改用户配置的默认时段；若折叠区存在安排但当前时间和跳转目标均不在其中，则继续通过折叠条数量提示，避免时间线被低相关时段拉长。
- 月视图的日期格只展示完成、推进和未推进数量，以及今日总进度的轻量视觉摘要。截止事项使用具有紧迫程度区分的标记；点击日期后在右侧展示当天完整任务列表与进度变化。
- 周视图工具栏固定提供“上一周”“回到本周”“下一周”和可点击的日期范围；前后切换每次移动完整 7 天，日期范围入口打开轻量周选择器。周以周一开始，日期头保持吸顶，今天同时以“今天”文字和描边标明；单击日期头进入该日的连续日视图。
- 周视图顶部设置可折叠的全天区域，只承载不占用时长的截止旗帜、项目截止旗帜和里程碑菱形；默认显示两行，超出后用“另外 N 项”展开原位列表。点击标记仍在右侧打开对应任务或项目详情，不把标记转换为执行时段。
- 周视图的日列变窄时按标题、时间、状态、进度、项目的顺序逐级隐藏低优先信息，始终保留标题和非纯颜色状态；悬停、键盘聚焦或选中后通过邻近操作条与右侧详情提供完整内容。中央区域不足时优先收起右侧面板和左侧导航，不把七列压缩到不可读宽度。
- 周视图键盘焦点在日期头之间用左右方向键移动，在时间网格中用方向键移动到相邻日期或吸附时间；`Page Up`／`Page Down` 切换前后周，`Enter` 对焦点所在标记打开详情、对空白时间执行既有创建小气泡，焦点移动不等同于创建或选择数据。
- 月视图使用固定六行日期网格，周一为每行起点；相邻月份日期以弱化样式保留，避免切月时网格高度跳动。工具栏提供上一月、回到本月、下一月和月份／年份选择器，切月时优先保持原日期序号，不存在时落到目标月最后一天。
- 月日期格按截止任务、项目截止／里程碑、完成与推进摘要的顺序展示最多三条重要信息，其余合并为“另外 N 项”；点击该入口或日期格空白处会选中日期，并在右侧显示当天完整列表，不使用弹窗，也不改变当前月份和滚动位置。
- 单击月视图中的具体截止或里程碑标记会直接在右侧打开对应详情，同时保留该日期的选中描边；右侧日期摘要提供显式“打开日视图”。第一版月视图只支持单日选择，不提供拖拽范围选择或在日期格内精细调整时长，防止与周／日排程职责重叠。
- 月视图中方向键按日移动焦点，跨行与跨月时连续移动；`Page Up`／`Page Down` 切换月份，`Home`／`End` 移到当前周首／末日，`Enter` 选中日期并打开右侧摘要。切换视图或从详情返回时保留所选日期，焦点与选中状态使用不同样式。
- 日历时间轴支持缩放：普通滚轮用于浏览，`Ctrl + 滚轮` 或触控板捏合用于调整纵向时间比例，并保持指针所在时间为缩放锚点。
- 工具栏同时提供“紧凑／标准／详细”三个可见缩放入口；每种日历视图分别记住上次的缩放程度。
- 日历执行卡片根据当前缩放和执行时段在屏幕上的可用高度自动调整信息量，而不是使用固定内容挤压短时段。
- 可用高度对应少于约 30 分钟时，只显示任务标题、分类色条和必要状态图标；约 30–59 分钟时增加开始／结束时间与细任务进度条；约 60 分钟以上时再显示所属项目、进度百分比和主要操作。
- 时间分级以实际渲染高度为准，因此缩放时卡片内容平滑增减，但不改变执行时段的真实开始、结束或任务数据。
- 当前安排、待回顾和已完成状态同时使用边框、文字或图标区分，不只依赖颜色；临近截止只在卡片上显示小旗帜，完整截止日期在悬停、选中或详情中查看。
- 卡片高度不足以容纳操作时，鼠标悬停或键盘选中后在卡片旁显示轻量操作条；双击始终在右侧打开任务详情。
- 分类颜色只用于窄色条或极淡背景，避免大量日历块形成高饱和色墙。
- 今天的时间轴显示带时间标签的当前时间线，并以极淡背景区分已过去区域；滚离当前时间后显示带方向提示的“回到现在”按钮。
- 当前时间落入某个执行时段时，任务卡以高亮边框和轻微光晕标记“当前安排”，不自动声称用户正在执行；卡片使用细时间条显示本时段已过去多久，并与较粗的手动任务进度条明确分开。
- 已结束但任务尚未完成的执行时段进入“待回顾”，显示时段已结束和当前手动进度，提供“更新进度”“继续安排”和“本次未推进”；未获用户确认前不自动判为未执行。
- 今日任务列表按“当前安排／待回顾／接下来／已完成”组织；当前没有安排时突出显示当前空档，并允许快速安排任务。
- 日历可叠加显示计划与实际：原执行时段使用淡色虚线轮廓，实际执行记录使用实色层，从实际开始延伸到实际结束或当前时间。
- 提前、延后或实际重叠只如实呈现，不反向移动原计划或自动推开其他任务；工具栏提供“显示实际记录”开关，并支持在自定义界面中隐藏。

## 今日页

- 今日页是行动优先的入口而非统计仪表盘；顶部只显示日期、今日总进度条和临期任务数量，投入时间、准时率及分类占比等详细数据留在“回顾”页。
- 页面最醒目的“现在”模块始终只呈现当前最需要决定的状态：活动执行显示本次用时与“结束本次”；当前安排尚未开始时显示“开始本次”；错过开始时显示挽救操作；当前为空档时显示下一项安排和快速安排入口。
- 存在并行活动执行时，“现在”模块明确列出全部活动任务，但不为每个任务复制一套大型面板。
- “现在”模块下方显示当天纵向时间线；进入今日页时让当前时间位于视野中央附近，同时保留用户主动滚动后的阅读位置。
- 待回顾任务排列在“现在”模块之后、后续日程之前，避免需要处理的历史时段被埋住；已完成任务默认折叠在底部，可展开查看当天成果。
- 今日页右侧继续使用统一任务池，不复制另一套待办列表；用户可从任务池拖入当天时间线或使用快速安排。

## 拖拽排程

- 从任务池拖入日历时默认按 15 分钟吸附，并实时预览开始时间、结束时间和可放置区域。
- 缩放只改变时间轴视觉密度，不自动改变吸附粒度；设置中可将吸附改为 5、10、15 或 30 分钟。
- 日历工具栏提供可见的磁铁按钮，显示“吸附 15 分钟”等当前状态；关闭后进入自由拖动。拖拽期间按住 `Alt` 可临时反转当前吸附状态，并持续显示精确时间预览。
- 拖到空白时间时直接放置；拖到已有任务的上方或下方时显示插入线，并默认执行“插入并后移”。
- 插入悬停期间，目标位置之后的任务像手机桌面图标让位一样平滑移动，实时预览新的时间位置；松手后才提交，拖出有效区域则全部复原。
- 在已有任务中央悬停约半秒时，两张卡片使用吸附聚拢动画并显示“同时安排”；此时松手才创建重叠时段，无需额外选择菜单。
- 边缘插入与中央重叠使用不同落点、动画和文字反馈；重叠后的任务并排或错层显示并标明同时安排的数量，但不会合并数据或改变任务所属结构。
- 同一时间并行 2–3 项时，日历卡片并排等宽显示；每张卡片仍可直接选中和拖动。并排直接展示的上限固定为 3 项，避免继续压缩后失去可读性和可操作性。
- 同一时间达到 4 项以上时，仅直接显示前两项，并使用一张轻微叠放的“另外 N 项”汇总卡；点击汇总卡会在原位置旁展开临时列表，列出全部并行任务，但不会创建文件夹、合并任务数据或改变时间安排。
- 在并行组中选中某一项时，该卡片仅在视觉层级上短暂浮到最前，不改变日历顺序；键盘用户可用左右方向键在同组任务之间切换，点击展开列表外的空白处会将列表收起。
- 拖动任务进入重叠区域时，预览需提前展示松手后的并排或“另外 N 项”折叠结果；正在执行的并行任务全部保持高亮，“现在”模块同步列出全部活动任务。
- 鼠标移入日历空白时段时，显示淡化的 `＋` 与对应时间；单击后在该位置展开小气泡，提供主要入口“新建任务”“从任务池安排”和次要入口“时间块”，不会仅因点中空白便直接创建数据。
- 在空白时段中纵向拖动会框选准确的开始与结束时间，并在拖动中持续显示时间预览；松手后打开同一个锚定小气泡并预填所选时段，按 `Esc` 或点击其他位置可取消。
- 日历空白时段不绑定双击快捷操作，避免与单击和框选手势冲突；键盘聚焦空白时间后可通过显式的 `＋` 入口执行相同操作。
- 当多选任务仍处于选中状态时，点击日历空白时段不打开普通新建菜单，而是直接预览将所选任务按当前顺序从该时间起依次排入；提交后沿用批量选择转移与整组撤销规则。
- 时间块只需要标题、起止时间、可选重复、提醒与备注；它显示在日历中并占用自动排程容量，但不进入任务池、不显示任务进度，也不计入任务完成率。第一版不提供地点、参与人、附件或外部日历同步。
- 时间块的详情提供“转为任务”；转换时预填可复用信息并建立对应任务及执行时段，原时间位置保持不变。普通任务安排不会被快捷操作意外降级为时间块。
- 自动排程始终把时间块视为不可用容量，不会自动生成与其重叠的任务执行时段；第一版不增加“忙碌／空闲”等时间块子类型。
- 用户手动把任务拖入时间块中央时，预览使用“与时间块同时安排”的明确文案，与普通任务间的重叠反馈区分；松手后在落点附近显示小气泡，提供“仍然安排”“放到时间块之后”和“取消”。
- 用户确认“仍然安排”只覆盖本次手动操作，不修改之后的自动排程规则；调整任务时长而侵入时间块时沿用相同确认。时间块与任务仍保持独立数据，重叠不会建立关联。
- 插入导致任务超出当前默认时段时，拖动中使用半透明卡片预览被推到后续默认时段或日期的任务；松手后通过锚定小气泡明确受影响数量和新日期，确认后才提交。
- 用户取消跨时段确认时，所有受影响任务恢复拖动前的位置；没有跨时段的普通插入直接提交，不增加确认步骤。
- 拖拽提交后在底部显示约 5 秒的轻量结果提示和“撤销”操作；若一次拖拽移动了多项任务，撤销会整体恢复该批变更。
- 鼠标悬停或键盘焦点位于结果提示时暂停消失计时；提示消失后仍可通过 `Ctrl + Z` 撤销，连续拖拽支持逐步撤销。
- 日历中的执行时段可以拖回右侧任务池；拖动期间任务池变为明确的“移回任务池”落区。放下后只取消该执行时段，保留任务、进度、历史及其他日期的执行时段，并提供相同的撤销提示。
- 日历任务的右键菜单提供“取消本次安排”，与反向拖拽等价并可直接撤销；同时提供“取消全部未来安排”，先用锚定小气泡显示受影响时段数量，确认后才让任务完整回到任务池。
- 放置后的执行时段可以通过拖动底边改变长度，动效应包含轻量浮起、落点反馈和回弹。
- 向下拉长并碰到后续任务时，后续任务实时向后让位；若产生跨默认时段或跨天移动，使用与插入相同的预览和小气泡确认。
- 向上缩短任务只释放空档，不自动吸附或提前后续任务；由调整时长产生的整组变化可一次性撤销。
- 用户可以直接编辑时间并精确到任意分钟，吸附规则不限制最终数据。
- 在连续日视图中拖拽任务靠近顶部或底部时自动滚动，距离边缘越近速度越快；指针返回中央后立即停止。
- 跨过午夜时保持日期分隔线醒目，并持续显示新的日期、开始时间和结束时间，使任务可以一次拖到前一天或后一天。

## 自动排程交互

- “自动排程”的固定说明为“仅追加到空档，不调整已有安排”；运行前先锁定既有执行时段、时间块与不可用范围，再计算未来 7 天真正可用的空档。
- 用户主动点击“自动排程”后，第一步展示目前能够放入可用空档的候选任务，由用户勾选本次想安排的任务；不会直接为任务池中的全部任务生成安排。
- 任务的“单次投入时长”是自动排程优先尝试的目标长度，而不是默认不可拆分的硬约束；当空档较短但仍达到最低有效时长时，任务仍可进入候选列表，并显示“可安排 25/40 分钟，剩余部分以后继续”等明确说明。
- 全局最低有效时长默认 15 分钟，设置中可选择 5、10、15、20 或 30 分钟；短于该阈值的空档不用于自动排程，但仍允许用户手动放置任务。
- 单个任务可开启“需要连续时段”；开启后，只有存在不短于该任务单次投入时长的连续空档时才进入候选列表，不会自动拆成多个较短时段。
- 拆分生成的执行时段只表示一次计划投入，不自动换算、增加或预测任务完成度；进度仍由用户手动确认。
- 暂时无法安排的任务不混入主要候选列表，只在底部以“另有 N 项暂时无法安排”折叠显示；展开后可查看缺少可用时长或约束冲突等确定性原因。
- 候选页打开时，系统按“截止日期 → 优先级 → 任务池顺序”进行一次确定性模拟，并默认勾选一组能够共同放入未来 7 天现有空档的任务；这组任务标记为“推荐本次安排”，其余能够单独安排但未进入当前容量组合的任务放在“其他可安排任务”中且默认不勾选。
- 默认勾选只减少选择步骤，不写入日历、不提高任务自身优先级，也不跨越用户已有安排、时间块或默认时段；用户可以逐项取消、改选其他任务，并通过“清空选择”或“恢复推荐”快速回到明确状态。
- 候选页顶部持续显示实时容量摘要，例如“已选 4 个任务 · 预计 6 个时段 · 使用 2 小时 10 分 / 可用 3 小时 · 剩余 50 分”；任务没有预计耗时时，容量计算采用该任务的单次投入时长或全局默认单次投入时长，不虚构完成整项任务所需的总时长。
- 每个已选任务在当前组合下显示“可完整安排”“可安排 25/40 分钟”或“当前组合中放不下”等中性结果。用户仍可暂时选择超过总容量的任务以比较和替换；此时摘要改为“超出 N 分钟”，并在生成草案前明确列出将只能部分安排或暂时无法安排的项目，不使用失败、落后等惩罚性措辞。
- “生成排程草案”在未选择任务时保持不可用并提示“请先选择至少一个任务”；候选页每次重新打开时重新计算推荐组合，用户对本次勾选的临时修改不改变任务的长期优先级或以后运行自动排程时的默认规则。
- 用户确认候选任务后才进入排程预览；建议生成的执行时段使用半透明卡片，与既有安排明确区分，且不会移动、缩短、删除或覆盖既有安排。
- 预览顶部汇总本次选择的任务数、建议时段数、使用时长和仍未安排的部分；每张建议卡说明可解释的主要依据，例如临近截止、高优先级或课程下一节。
- 用户可在预览中拖动建议卡、取消选择单项，并通过“应用全部”“仅应用已选”或“放弃预览”结束；放弃时真实日历保持原样。
- 应用后的所有新增与调整作为一个操作组写入，并支持一次 `Ctrl + Z` 整体撤销。
- 容量不足的任务继续留在任务池，并明确显示缺少的可用时长或无法安排的约束；系统不会为了凑出结果而覆盖时间块、延长默认时段或制造不可见重叠。
- 设置中可开启自动排程辅助；开启后系统只主动提示“现在有 N 个任务可以安排”，点击提示后仍进入候选选择与草案预览，不会在后台直接写入日历。

## 系统托盘

- Windows 开机自启时 Daymark 静默进入托盘，不自动显示主窗口或抢占系统焦点；启动摘要仍按“每次开机／每天一次／不提醒”的用户设置发送。
- 点击启动摘要打开今日页并定位到临期与逾期区域；从开始菜单或桌面图标主动启动时默认进入今日页，设置中可改为“日历”或“上次页面”。
- 点击执行提醒打开今日页并定位、高亮对应执行时段；点击截止或里程碑提醒直接打开对应任务或项目详情，不自动开始执行。
- 全局“快速新建”快捷键只唤起轻量快速收集窗口，不要求先显示或加载完整主窗口。
- Daymark 关闭主窗口后继续驻留系统托盘；左键单击托盘图标显示或隐藏主窗口，恢复时保留上次页面、筛选和滚动位置。
- 主窗口右上角关闭按钮默认只隐藏到系统托盘；首次执行时显示一次系统提示：“Daymark 仍在托盘运行，右键托盘图标可退出”，之后不重复打扰。
- 设置中的“关闭窗口时”提供“隐藏到托盘（默认）”“每次询问”和“直接退出”三种策略；选择直接退出时明确说明退出后桌面提醒和全局快捷唤起将不可用。
- 右键单击托盘图标打开原生快捷菜单；菜单顶部显示当前正在执行的任务，并提供“打开任务”和“结束本次”。
- 从托盘选择“结束本次”只保存本次执行的结束时间，不把整个任务标记为完成；主窗口打开后进入对应的非模态“本次小结”，允许跳过或稍后补写。
- 没有正在执行的任务时，托盘菜单显示下一项安排及“打开今日”；点击下一项只定位到对应任务，不自动开始执行。
- 托盘常驻操作包括“快速新建任务”“打开今日”和“设置”；完整编辑、排程和进度调整仍在主窗口完成，避免快捷菜单拥挤。
- “退出 Daymark”独立放置在菜单最底部并与普通操作分隔；只有该操作或“直接退出”关闭策略真正结束后台进程，普通关闭窗口仅隐藏到托盘。没有活动执行时，明确选择退出后不再追加二次确认。
- 真正退出时若存在活动执行，在退出入口附近显示锚定小气泡，列出任务名称和活动执行数量，并提供“结束于现在并退出”“退出，稍后确认时间”和“取消退出”。
- “结束于现在并退出”立即为全部活动执行保存退出时刻，下次打开时允许补写本次小结；“退出，稍后确认时间”将其标记为待确认，并沿用下次启动时选择实际结束时间的处理卡片。
- 退出确认默认聚焦“结束于现在并退出”；不提供“退出后继续计时”，因为应用进程停止后无法形成可靠的实时记录。

## 快速收集

- 左侧设置入口上方提供“新建任务”按钮，并支持从托盘状态唤起的全局快捷键。
- 快速新建首先只要求任务名称，按 Enter 后立即进入任务池；分类默认沿用最近一次选择，并允许快速切换。
- 截止日期、预计耗时、单次投入时长、所属项目等字段放在可选的“更多设置”中，不阻塞快速收集。仅含空格的名称不能保存并原位提示“写下要做的事即可”；同名任务允许创建，只提供非阻塞的已有任务查看提示，因为不同项目或日期可以合理同名。

## 完整任务创建

- 快速收集的“更多设置”、日历新建、项目内新增和“基于此重新开始”共用右侧创建面板。只有名称必填；展开区依次为名称／分类／所属项目，以及截止日期／优先级／单次投入时长；分类沿用最近选择，项目按来源预填，截止留空、优先级普通，单次时长沿用全局值且不写入任务覆盖。
- “更多排程设置”默认折叠，包含预计耗时、需要连续时段、置顶方式和初始完成度，默认分别为空、关闭、关闭和 0%；建议耗时必须显式采用。普通任务不内嵌重复规则，只提供“需要重复？创建重复习惯”入口并保留名称和分类。
- 从日历框选进入时额外显示独立的“本次安排”摘要；保存以一个操作组创建任务和执行时段，不把该时段写成截止日期或预计耗时。底部固定“取消／创建任务”，支持 `Esc`／`Ctrl + Enter`；关闭已填写表单使用小气泡确认，错误时保留输入并聚焦首个错误。
- 创建成功后恢复来源页面和滚动位置，在任务池中高亮新任务；日历来源同时定位新时段。轻量结果提示提供“撤销”和“继续添加”，不强迫补齐可选信息。

## 重复习惯创建与编辑

- 重复习惯使用与任务一致的右侧渐进式面板，最小表单只有名称、分类和重复规则；名称必填，分类沿用最近选择，重复规则默认“每天”。顶部常用模板为“每天”“工作日”“周末”“每周选择日期”和“自定义”，选择后立即显示自然语言摘要与接下来 5 次发生日期。
- “自定义”展开开始日期、每隔 N 天／周／月、周几或每月日期；每月日期在某月不存在时使用该月最后一天，并在预览中明确展示。结束条件默认“持续”，也可选“截止到日期”或“按规则发生 N 次”；次数按发生日期计数，不要求完成才计数。暂停与结束条件分开，暂停不会改写结束日期或历史。
- “安排与提醒”默认折叠：单次投入时长沿用全局默认值；默认使用分类适用的默认时段参与候选排程，并采用“安排前置顶”，但不会仅因生成发生项就写入日历。用户也可显式指定固定开始时间；此时未来发生项按规则生成执行时段，执行提醒复用全局提醒设置。没有实际执行时段时不发送执行提醒。
- “未完成处理”默认选择“不累积，仅保留原日记录”，另可选择“未完成则顺延一次”；后者始终最多存在一份活动欠项。“补到今天”是单次主动操作，不修改重复规则，也不会把连续遗漏一次性复制到今天。
- “持续推进”默认是独立习惯；高级设置可关联一个已有普通任务或项目子任务，但不能直接关联整个项目。发生项保存自己的日期状态和执行记录；关联任务保留唯一的长期完成度与投入历史，本次小结可打开该任务的统一进度编辑器，但不会按次数或时长自动增加进度。
- 编辑规则时默认从“下一次发生”生效，也可选择一个未来生效日期；已开始、已完成和过去的发生项及其记录保持原样。尚未开始的未来发生项按新规则重新生成；若其中已有日历时段，应用前必须预览受影响日期和数量并由用户确认，不静默移动或删除。
- 单个发生项只提供“改到其他日期”“跳过本次”“补到今天”等本次操作，不修改整套重复规则；编辑面板底部固定“取消／创建习惯”或“保存未来规则”，输入错误时保留内容，创建与批量更新未来发生项均可作为一个操作组撤销。

## 搜索与快捷键

- 默认使用 `Ctrl + K` 打开全局搜索与快速跳转，支持搜索任务、项目和分类，并直接打开对应详情。
- `Ctrl + K` 打开统一面板，但顶部明确分为“搜索”和“命令”两个入口；默认停留在搜索。输入 `>` 可以作为进入命令的可见加速方式，但不是唯一入口；切回搜索不会丢失刚才的查询文本。
- 搜索结果固定按“任务”“项目”“分类”分组，每组先显示最多五项并提供“查看全部”。匹配排序依次为完整名称、名称开头、连续子串、按顺序出现的字符；同等级任务按截止日期再按任务池顺序，项目按最近推进时间，分类按名称。匹配字符高亮，算法保持本地、确定性且不使用 AI。
- 搜索页提供未完成、临期、无日期、分类和项目等可见筛选项；选中任务或项目时打开既有右侧详情或项目页，选中分类时打开任务池并应用该分类筛选。跳转后保留来源查询，返回时恢复结果、当前焦点和滚动位置。
- 查询为空时显示最多五个最近打开的任务或项目，以及“新建任务”“打开今日”“打开日历”等常用安全命令；最近访问仅按本地打开时间排列，可在面板中清除，不参与有查询时的相关性排序，也不包含已删除对象。
- “命令”只包含页面跳转、打开快速创建、打开自动排程候选、切换已有视图或显示设置等不会直接改写核心数据的动作。删除任务／项目、清除历史、恢复备份、直接退出活动执行，以及直接完成、修改进度或批量移动日程等命令不进入面板；相关关键词最多跳转到对应页面或详情，由原界面继续执行既定确认。
- 面板内上下方向键移动结果，左右方向键或 `Tab`／`Shift + Tab` 在搜索、命令和筛选区之间移动，`Enter` 打开结果或执行安全命令；第一次 `Esc` 清空非空查询，查询已空时再次 `Esc` 关闭，关闭后焦点返回原触发位置。再次按 `Ctrl + K` 也可关闭面板。
- 无匹配时沿用主要空状态规则：显示原查询、当前筛选和“清除搜索”，并在查询可作为名称时提供次要的“新建‘查询’任务”；不会自动创建，也不会用模糊匹配替用户打开低置信度结果。
- 任务列表和任务池获得键盘焦点后，`方向键` 在可见任务卡之间移动选中焦点，`Enter` 打开当前任务详情；焦点样式必须清晰可见，但不等同于多选状态。
- 多选模式中使用 `Space` 选中或取消当前任务，`Ctrl + A` 选择当前筛选范围内的全部任务；`Esc` 清除选择并退出多选。
- `Delete` 删除当前选中任务或多选任务，并沿用对应影响范围的小气泡或大型确认规则；`Ctrl + Z` 撤销最近一次拖拽、批量修改或删除等可撤销操作。
- 搜索结果提供未完成、临期、无日期和所属分类等确定性筛选，不使用 AI。
- 设置页提供统一的快捷键管理，搜索、快速收集等快捷键均可由用户重新录入，不在应用中写死。
- 任务选择、打开、多选、删除和撤销等快捷键同样列入快捷键管理并允许修改；按钮悬停提示和更多菜单显示当前实际绑定，修改后同步更新，避免只能依赖说明文档记忆。
- 搜索快捷键默认只在 Daymark 窗口活动时生效；快速收集可以注册为系统全局快捷键，以便应用隐藏到托盘后继续唤起。
- 快捷键设置明确标注“应用内”或“全局”，并检测应用内重复及系统注册失败，避免静默抢占或无效。

## 任务进度

- 任务详情提供可拖动的进度条、快捷增加按钮和精确百分比输入。
- 常驻且可直接拖动的任务进度条只出现在任务详情和“本次小结”两处，避免相同编辑控件散落在任务池、日历和回顾页面中。
- 任务池卡片上的进度条只负责展示，不接受拖动；卡片右侧的百分比使用轻量编辑标记，点击后在原位置附近展开锚定小气泡。
- 进度编辑气泡复用统一的进度编辑器，提供进度条、`+5%`、`+10%`、“完成”和精确百分比；点击空白处收起，不使用居中弹窗。
- 日历任务块和今日列表默认只展示任务进度；用户明确点击“更新进度”时打开相同的进度编辑气泡。紧凑卡片仍可通过百分比进入该编辑器。
- 项目卡片上的总进度由子任务计算，日报、周报和月报中的进度来自历史记录；这些汇总进度均只展示，不能直接拖动修改。
- 实际投入时间仅由用户事后选填，可通过“记录投入时间”快速增加分钟数；应用不运行后台计时，也不催促补填。
- 未记录投入时间不影响任务推进、完成或排程；它只用于用户希望参考的耗时统计。
- 设置中提供默认关闭的“开始签到”；开启后，当前安排的任务显示“开始本次”按钮，点击只记录实际开始时间，不自动修改任务进度。
- 开始签到宽限期可设置为 3、5、10 或 15 分钟，默认 5 分钟；提前开始或不晚于宽限期开始均计为准时。
- 未签到的时段记为“未记录”而非自动判定迟到，并允许事后补填实际开始时间；统计同时显示准时启动率与记录完整度。
- 开启开始签到后，计划开始时间与宽限期已经过去但仍未开始时，今日页显示一次非模态“重新安排一下”挽救卡片，提供“现在开始”“延后 10 分钟”“重新选择时间”和“本次跳过”。
- “现在开始”记录真实开始时间；超过宽限期时如实计为较晚开始，但不使用红色失败反馈。“延后 10 分钟”和“重新选择时间”只调整本次执行时段并提供撤销，“本次跳过”不完成或删除任务。
- 每个执行时段只产生一次挽救提醒，用户忽略后不连续催促；时段结束时仍进入待回顾。设置中可以独立关闭挽救提醒而保留普通执行提醒。
- 挽救提示使用面向下一步的中性文案，不出现“你又拖延了”“打卡失败”等评价性表达。
- 每个执行时段支持三种记录路径：实时“开始本次／结束本次”、事后补填实际开始与结束日期时间，以及一键“按计划记录”并采用原计划时段作为实际时间。
- 即将到来的任务允许提前开始并记录当前时间；提前开始计为准时。待回顾任务显示“按计划记录”“补填实际时间”和“本次未推进”。
- “按计划记录”只完成本次执行记录，随后仍可选填任务进度和本次小结，不自动将整个任务设为完成。
- 准时反馈使用周趋势和中性语言，不提供断签、红叉或失败惩罚；关闭开始签到后，任务卡不再显示该按钮。
- 点击“开始本次”后使用柔和扩散光效反馈，按钮切换为实际开始时间和“结束本次”；可选显示本次实际用时，不使用倒计时制造压力。
- “结束本次”只结束当前执行并记录实际投入，不自动完成任务；任务完成仍由用户把手动进度调整到 100%。
- 若比计划提前结束，本次小结提供“保留空档／休息”“安排下一项”和“从任务池选择”，不会自动占用剩余时间或把休息评价为浪费。
- 点击“结束本次”时立即保存结束时间，随后在任务旁展开非模态的“本次小结”浮层；关闭或跳过浮层不会让执行继续计时。
- 已签到执行到达计划结束时间时不会自动结束；应用显示轻量提示，提供“结束本次”“继续 10 分钟”和“自定义延长”。
- 已有任务正在记录时，再点击另一任务的“开始本次”，按钮旁显示“结束上一项并开始／同时开始／取消”；默认聚焦结束并切换，但允许用户明确创建并行执行。
- 并行执行时当前区域同时显示所有活动任务，不暗中暂停或结束任何一项。
- 延长执行时日历块实时增长；若影响后续任务，沿用任务让位、跨时段确认和整组撤销规则。用户未响应时实际用时继续累计，并允许在本次小结中修正。
- 应用重新打开时若发现尚未结束的执行，在今日页顶部显示非模态“上次执行尚未结束”卡片，提供按原计划结束、选择实际结束时间和仍在进行；确认前将时长标为待确认且不计入回顾统计。
- 本次小结显示可修正的实际投入、可拖动的任务进度与本次推进量，并提供可选的 1–5 星“本次满意度”、多选感受标签和自由评论。
- 默认感受标签包括“专注”“顺利”“有收获”“比预计难”“被打断”“疲惫”“卡住”和“想继续”；除实际投入外均可跳过，并可从历史记录稍后补写。
- 设置中提供可修改的全局默认单次投入时长，初始建议为 30 分钟；单个任务可以用自己的单次投入时长覆盖它。
- 当任务既没有预计耗时也没有单独设置单次投入时长时，自动排程使用全局默认值安排一个尝试时段；该时段不代表任务应当完成，也不会反向填写总预计耗时。
- 进度条默认按 5% 吸附；精确输入允许任意整数百分比。
- 拖动结束后才保存一次进度变化，避免连续写入历史记录。
- 进度变化使用平滑过渡，并短暂显示当天增加的百分比。
- 任务达到 100% 时自动标记完成，播放克制的完成动画，并移动到当天的已完成区域。
- 完成操作提供即时撤销；将完成度重新调低于 100% 时，任务恢复为进行中。

## 项目页面

- 项目总览使用项目卡片，显示耗时加权进度、最近截止日期、任务数量和下一个建议任务。
- 项目进度自动选择完整且可解释的权重来源：全部子任务都有已确认预计耗时时按预计耗时加权；否则，全部子任务都有媒体时长时按媒体时长加权；两者都不完整时按子任务等权计算。
- 未经用户采用的建议耗时不参与项目进度计算；项目卡明确标注当前使用“预计耗时”“媒体时长”或“任务数量”等哪种计算依据。
- “创建项目”窗口同时提供普通空白项目创建，以及“从课程导入”按钮；课程不占用独立导航入口，也不是独立的项目类型。
- 项目提供可选的“按顺序推进”设置；课程导入时默认开启，普通空白项目默认关闭。该设置影响下一任务推荐和自动排程顺序，但不会锁定任务或禁止跳过。
- 项目可以设置项目截止日期，表示希望所有子任务完成的日期；项目卡和详情页展示距离截止日期的剩余时间与当前排程风险。
- 项目可以设置多个项目里程碑，作为项目截止日期之前的阶段目标。
- 项目里程碑支持三种目标：在日期前完成到指定有序任务、在日期前完成指定数量的任务、在日期前达到指定的项目进度百分比。
- “完成到指定分 P”要求该分 P 及之前分 P 均完成；“完成若干分 P”允许跳集；“达到项目进度”使用耗时加权且由任务手动进度驱动的项目进度。
- 里程碑显示在项目详情和日历中，并作为自动排程与风险提示的中间约束；单个分 P 的独立截止日期只用于该分 P 存在特殊外部期限的情况。
- 到期未达成的里程碑保留原日期、原目标和实际结果，例如“完成 3/5，未达成”，不自动改写历史。
- 未达成里程碑提供“将剩余目标纳入后续计划”操作；只有用户确认后，差额才参与后续里程碑或自动排程。
- 新建里程碑后先显示完成目标所需的建议节奏，但不会立即修改日历；用户点击“安排此里程碑”或主动运行全局自动排程后才生成执行时段。
- 项目里程碑提醒默认继承全局截止提醒规则；单个里程碑可以覆盖为自定义提醒时间或关闭。通知点击后打开对应项目和里程碑，不自动启动任务或改动排程。
- 日历使用菱形节点表示项目里程碑，使用旗帜节点表示项目最终截止日期；两者不混用同一种标记。
- 里程碑已达成时降低视觉强调并显示勾号，存在延期风险时使用琥珀色提示，已逾期时使用红色提示；状态同时使用文字或图标表达，不只依赖颜色。
- 点击日历中的里程碑后，右侧面板显示目标、当前结果、剩余量及“安排此里程碑”等操作。
- 项目详情展示项目说明，以及待执行、待续和已完成任务分组与最近进度记录。
- 项目任务继续使用统一的任务池和日历，不建立独立排程系统。
- 第一版使用分组列表，不加入复杂看板。
- 项目总览在宽工作区使用两列卡片、窄工作区使用单列；筛选为“进行中／已暂停／已完成”和“全部／有截止风险／无截止日期”，排序提供“截止与风险（默认）／最近推进／项目进度／名称”。筛选和排序在离开页面后保留，不增加按分类筛选，因为分类属于任务而非项目。
- 项目卡主体打开项目详情；可见的展开箭头在原卡片内展示最近里程碑和最多三个待推进任务，不改变卡片顺序。卡片主操作为“继续下一项”，次操作“安排项目”进入仅含该项目任务的自动排程候选流程，仍需选择、预览和确认。
- 项目总览没有项目时显示“创建空白项目”和“从课程导入”；筛选无结果时保留现有项目数量并提供“清除筛选”，不使用暗示用户尚未努力的空状态文案。
- 项目详情顶部固定显示名称、项目进度及计算依据、截止日期和当前风险；主体先显示项目说明与里程碑时间线，再显示待执行、待续、已完成三组任务，近期记录置于末尾。选择子任务继续使用统一右侧任务详情，项目页面本身不复制任务编辑表单。
- 任务区顶部提供“添加任务”和显式“调整顺序”模式：添加任务使用完整任务创建表单并预填当前项目；调整模式显示拖拽把手和保存／取消，改变的是项目内建议顺序与后续推荐，不移动既有执行时段、不修改完成状态或历史。已完成组默认折叠，不能通过拖入其他分组改变状态。
- 里程碑时间线始终提供“添加里程碑”，点击节点或添加按钮在右侧打开统一表单，按已有三种目标、日期和提醒规则编辑；保存前显示目标摘要，删除使用锚定确认。已到期里程碑的原目标和结果保留在历史中，修改只作用于当前或未来目标。
- 项目详情的“在日历中安排”会打开日历并将任务池筛选为当前项目；从日历、任务详情或里程碑返回时恢复项目页的任务分组、展开状态和滚动位置。返回项目总览时同样恢复原筛选、排序与滚动位置。
- 课程项目在任务池中以单张可展开卡片呈现，避免大量分 P 淹没普通任务。
- 展开的分 P 列表少于 10 项时按实际高度显示，达到 10 项后固定为约 10 行高度，并在卡片内部使用滚轮滚动。
- 打开或展开课程项目时，列表自动滚动到最近一次实际推进的分 P，而不是最早未完成分 P；已完成分 P 保留原顺序，但文字和状态降低视觉强调。
- 若当前学习位置之前仍有未完成分 P，课程卡显示轻量的遗漏提示，但不自动跳回、不阻止继续后面的内容。
- 当当天安排的分 P 未完成时，用户可选择“单项顺延”，只把该分 P 的后续安排移到下一个可用时段；后面已经排好的分 P 保持不动。
- 用户也可选择“级联顺延”，把该分 P 和后面已经排好的课程任务按原顺序整体后移；执行前展示受影响的分 P、日期和截止日期风险预览。
- 级联顺延可以产生超过项目截止日期的安排，但必须在预览和项目状态中显示预计延期天数；系统不会随之修改项目截止日期。
- 出现预计延期时提供“重新压排到截止日前”操作，但只有用户主动触发后才会尝试重新安排。
- “重新压排到截止日前”只使用截止日前已有的默认时段和日历空档，不延长用户设定的每日可用时间，也不覆盖其他任务。
- 若可用容量不足，系统停止生成虚假结果，明确显示仍缺少的总时长，并由用户选择增加可用时段、调整截止日期或减少项目范围。

## 截止任务页面

- 截止任务页使用单列高密度清单，固定分为“已逾期”“今天”“未来 7 天”“更晚”，组标题显示数量并可折叠；组内先按具体截止时间，再按优先级和任务池顺序排列。工具栏支持分类、所属项目和是否已有安排筛选，筛选状态在返回页面后保留。
- 每行显示任务标题、分类／项目、截止日期、手动进度和下一次安排；截止日期沿用相对日期／实际日期切换。单击行在右侧打开统一任务详情，返回后保留分组展开和滚动位置；“在任务池中定位”打开日历及右侧任务池并高亮该任务，同时提供返回截止任务页的上下文入口。
- 可见“多选”按钮进入批量模式，批量改期只提供“改到某日”“顺延 N 天”和“清除截止日期”；顺延保留原有具体时刻，改到某日对已有时刻同样保留、纯日期任务仍保持纯日期。操作只修改所选任务的截止日期，不移动执行时段，也不修改项目截止日期或里程碑，并以一组操作提供撤销。
- 批量改期提交前显示受影响任务数、跨过今天或项目截止日期的数量；提交后重新计算截止风险并可进入自动排程候选，但不自动重排。无截止任务时提供“新建任务”和“查看全部任务”，筛选无结果时只提供“清除筛选”。

## 课程批量导入

- 课程导入是创建普通项目的一种方式：它预填项目信息，并批量生成带原始顺序和媒体元数据的子任务。
- 用户可以粘贴 B 站普通视频链接；系统从链接中提取 BV 号并读取公开元数据，获得课程标题、UP 主、封面以及每个分 P 的顺序、标题和媒体时长，不依赖 AI，也不下载视频。
- 用户也可以粘贴课程分集文本；系统使用确定性格式规则识别标题行及 `mm:ss` 或 `hh:mm:ss` 时长，作为其他来源和链接读取失败时的兜底方式。
- 导入前展示可编辑预览，自动按原顺序标记 P1、P2 等集数，不静默创建任务。
- 确认导入后，整门课程成为一个课程项目，每个分 P 成为一个带原始顺序的子任务。
- 完成一个分 P 后建议继续下一个未完成分 P，但完成动作本身不会自动改动日程；系统不强制连续完成，也允许跳集和手动调整顺序。
- 用户主动运行自动排程时，若分 P 已有预计耗时，系统可从当前学习位置往后按课程顺序填充未来 7 天能够容纳的若干分 P；不会一次安排整门课程，生成的时段仍可拖动、修改或移除。
- 通过 B 站链接导入时，每个分 P 任务保存指向对应 `?p=序号` 页面的来源链接；任务卡和详情页提供“打开视频”操作，可直接进入该分 P。
- 第一版的“打开视频”使用系统默认浏览器，不在 Daymark 内嵌 B 站播放器，以沿用用户已有的浏览器登录状态并保持桌面应用轻量。
- 打开视频仅执行跳转，不自动启动计时、不跟踪观看行为，也不自动修改任务进度；任务进度仍由用户手动确认。
- 仅通过纯文本导入时不会猜测视频来源，因而默认不生成分 P 链接。
- 识别出的媒体时长单独保存，默认不填入预计耗时。
- 预计耗时允许一直留空；当媒体时长等客观依据存在时，任务可显示按明确规则计算的“建议耗时”，但不会静默写入预计耗时。
- 建议耗时只有在用户单项或批量点击采用后，才作为预计耗时参与排程和项目耗时加权进度。
- 第一版只在存在媒体时长等可测量依据时，通过固定加时或倍数换算等确定性规则生成建议耗时；普通任务缺少依据时不猜测，不使用 AI 或个人历史画像生成建议。
- 预览提供“使用媒体时长”“每集增加固定分钟”“按倍数换算”和“不设置预计耗时”等批量操作，结果仍可逐项修改。
- 导入预览使用带复选框的表格，默认选中所有标题有效且可导入的行；缺少媒体时长仍是有效行，只是不生成基于时长的建议。顶部持续显示“已选 N／共 M 项”，提供全选、取消全选和 `Shift` 连续选择；创建项目及预计耗时批量操作只作用于已选行，未选行保留编辑内容但不写入数据库。
- 预览行按来源顺序显示 P 序号、标题、媒体时长、建议／预计耗时和来源状态；标题与预计耗时可原位编辑，单行错误就地说明。选择状态使用稳定的导入行标识保存，编辑、滚动或重新计算建议耗时不会让复选框错位或重置。
- B 站重复检测使用 BV 号和分 P 的稳定来源标识，不只比较可变化的标题或 P 序号。检测到相同课程时，顶部显示已有项目、匹配分 P 数和新增分 P 数；存在新增内容时主操作为“只将新增分 P 加入已有项目”，已有分 P 锁定为跳过且不覆盖其标题、进度、投入、历史或日程，新分 P 的插入位置在提交预览中明确显示。
- 相同 B 站课程没有新增分 P 时，提供“打开已有项目”“仍创建独立副本”和“取消”；创建副本必须再次明确将产生多少个新任务。纯文本没有稳定来源标识，只把同一次粘贴中标题与时长均完全相同的后续行标为“可能重复”并默认不选，允许用户重新选中；不会据此自动合并或覆盖已有项目。
- 预览表格固定为约 12 行高度；超过约 100 行时启用既定虚拟化并保持键盘焦点、选择和滚动锚点。解析按批次显示“已识别 N／总计 M”（总数未知时只显示已识别数），允许在读取、解析和预览阶段取消；取消或单批失败后保留原链接／文本、已解析行、用户编辑和选择，重试从安全阶段继续而不清空表格。
- 超大课程最终写入仍使用既定单事务规则；提交按钮旁显示选中任务数和预计创建／新增到已有项目的结果。写入阶段不可安全取消时明确锁定选择并显示当前阶段，失败整体回滚；成功后直接定位新项目或已有项目中的首个新增分 P。
- 链接无法读取、视频受限或来源暂不支持时，保留已输入链接并明确提示原因，同时允许用户切换到文本导入，不丢失当前编辑内容。

## 首次使用与主要空状态

- 首次打开使用一个可随时跳过的三步引导，始终提供“跳过并进入 Daymark”：①用仅标题的快速收集写下第一件事；②可选设置一个或多个默认时段；③可选开启通知、启动摘要与开机自启。每一步都可单独跳过，未填写完整资料不会阻止进入今日页。
- 第一步只创建用户亲自输入的真实任务；Daymark 不默认写入示例任务、执行记录或进度，避免污染任务池与回顾。引导中的拖拽和卡片示意使用不落库的临时预览，离开引导即消失。
- 默认时段步骤提供工作日晚间等可编辑模板和“稍后设置”，但不预选为用户事实；跳过后手动排程完全可用，首次运行自动排程时若没有可用默认时段，再以非阻塞说明引导到对应设置。
- 通知权限只在用户点击“开启提醒”后向 Windows 请求；开机自启和全局快捷键也只在用户明确开启时注册，不在首次启动时连续弹出系统请求。启动摘要可以推荐“每天一次”，但未确认时保持关闭；拒绝或跳过后可在设置中重试。
- 所有空状态使用中性事实说明、一个主要操作和至多一个次要操作；不显示“你还没有努力”“连续失败”等评价。筛选无结果与真实无数据必须分开：前者优先“清除筛选”，后者才提供创建入口，且页面原有结构不因空状态完全消失。
- 今日页没有任务时主操作为“新建第一个任务”；已有任务但今天无安排时改为“从任务池安排”。日历空白时仍显示完整时间网格，当前或默认时段附近提示“从任务池安排”，次操作为“新建任务”。任务池无活动任务时主操作为“新建任务”，次操作为“创建项目或重复习惯”。
- 项目页真实为空时提供“创建空白项目／从课程导入”；截止任务页为空时显示“暂时没有带截止日期的未完成任务”，提供“新建任务／查看全部任务”；回顾周期没有执行或进度记录时不绘制全零图表，显示“有实际推进后，这里会出现回顾”，主操作为“前往今日”。
- 搜索尚未输入时只显示可搜索范围与示例关键词；无匹配时显示当前关键词和“清除搜索”，若关键词可作为任务名称则提供次要操作“新建‘关键词’任务”。从空状态完成创建或清除筛选后，焦点回到新内容或原列表起点，不让用户停留在已经失效的空状态。

## 设置页面

- 设置页使用六个固定分类：`外观`（主题、浅色／深色／跟随系统、界面缩放与减少动态）、`时间与排程`（默认时段、默认日历显示、全局单次投入时长、最低有效时长、自动排程辅助、吸附）、`提醒与行动`（执行／截止提醒、启动摘要、开始签到、宽限期与挽救提醒）、`启动与托盘`（开机自启、主动启动页面、关闭窗口行为）、`快捷键`、`数据与安全`（删除历史策略、自动／手动备份与恢复）。宽窗口使用页内左侧分类栏，窄窗口改为顶部吸附的分类选择器；主导航中的设置入口和页内分类不重复。
- 页面顶部提供本地设置搜索，只匹配设置名称、说明和预设同义词，不搜索任务数据也不执行命令。结果按分类显示完整路径，例如“提醒与行动 › 开始签到 › 宽限期”；点击后跳转、展开并短暂高亮对应设置，`Esc` 清空搜索。无结果时保留原输入并建议更短关键词，不使用 AI 猜测。
- 依赖项不隐藏：父开关关闭时，子设置置灰但保留原值，并在原位说明原因与“开启父设置”入口。例如关闭开始签到会禁用宽限期和挽救提醒；重新开启后恢复用户原值。搜索仍可找到被禁用项，并同时展示其依赖原因。
- 普通开关、单选和数值设置修改后立即保存并显示短暂“已保存 · 撤销”；默认时段列表和快捷键录入等包含多项修改的编辑器使用明确“保存／取消”，离开未保存编辑器时用锚定小气泡询问继续或放弃。第一版没有必须重启 Daymark 才生效的应用内设置，不显示虚假的重启提示。
- 每个分类底部提供“恢复本组默认”，通过锚定确认列出将改变的设置数量；页面最底部提供“恢复所有设置”，使用大型确认并明确不删除任务、项目、历史或备份，也不改变 Windows 已授予的系统权限。单个设置在值偏离默认时可通过轻量恢复图标还原。
- `数据与安全`将备份／恢复操作与未来删除历史策略分开；选择“始终全部删除”时在该行显示持续警示并用锚定确认说明只影响之后的删除。恢复备份继续沿用恢复前快照和大型确认，不新增“一键清空全部数据”等未确认危险能力。
- `提醒与行动`和`启动与托盘`分别显示 Windows 通知权限与开机自启注册的真实状态：未请求、已允许、已拒绝或不可用，以及已启用、已关闭或注册失败。系统拒绝时应用内开关不能伪装成已生效，应提供“打开 Windows 设置”或“重试”；全局快捷键同样显示注册成功或冲突，系统级操作完成后立即刷新状态。

## 本地数据与备份

- 核心数据持续保存到本地 SQLite；自动保存不要求用户手动点击保存。
- 应用每天创建一次本地滚动备份，默认保留最近 7 份，超过数量后只淘汰最旧的自动备份。
- 设置页提供备份列表、备份时间与文件大小，并提供“立即备份”“导出备份”和“从备份恢复”。
- 执行恢复前自动创建一份独立标记的“恢复前备份”，并在确认界面显示目标备份的时间、任务数和项目数；恢复错误时可用该备份撤回。
- “恢复前备份”不会因普通的 7 份自动备份保留规则而立即被淘汰。
- 可迁移备份包含任务、项目、进度记录、分类、主题、默认时段和提醒规则等用户数据与偏好。
- 备份不恢复开机自启注册、系统通知权限和窗口位置等当前电脑专属状态；迁移到新电脑后由用户重新确认这些设置。
- 第一版不依赖云端账户或在线同步，备份数据默认不离开用户电脑。

## 错误与恢复反馈

- 错误反馈按影响范围分层：字段格式、单条导入行和快捷键冲突使用行内说明；由某个按钮触发且可立即重试的失败使用锚定气泡；自动保存、自动备份、系统权限或只读状态等持续降级使用页面顶部横幅；只有数据库无法安全打开、备份恢复失败或退出可能丢失未保存内容时使用模态。普通成功仍使用轻量结果提示，不能用会自动消失的提示承载必须处理的错误。
- 所有错误提供用户可执行的下一步，至少在适用时包含“重试”“取消／返回”和折叠的“查看详情”；详情显示时间、操作阶段、稳定错误码和相关本地路径，可复制但默认不展示堆栈，也不包含任务正文、评论或其他私人内容。Daymark 不上传诊断、遥测或崩溃数据。
- 自动保存失败时不关闭编辑器、不回滚到旧值，也不允许界面继续显示成已保存；对应字段或对象标记“未保存”，顶部持续显示“保存遇到问题”，提供重试和“保存本地恢复副本”。待保存修改保留在内存并按原顺序重试；恢复副本只包含这些待提交修改，之后可由数据与安全页重新载入为待确认编辑。关闭窗口或退出应用前使用模态提供“再次重试／保存恢复副本／放弃未保存修改／取消退出”，危险的放弃操作不获得默认焦点。
- SQLite 可读但不可写时进入明确的“只读安全模式”：允许查看、搜索和导出已有任务、历史及备份，禁止普通创建、编辑和开始／结束执行，并持续显示原因与“重试写入／打开数据目录”；备份恢复只能从显式恢复模态进入，验证通过后再退出只读连接进行替换。若数据库连读取都失败，应用不创建空库覆盖原文件，而是显示恢复模态，提供“重试”“选择备份恢复”“打开数据目录”和“退出”。
- B 站链接与文本导入按“读取来源／解析内容／生成预览／写入数据库”显示阶段进度；读取、解析和预览阶段可取消并保留原链接、文本和已修正行，单行问题在预览表格原位标注。最终写入使用单个 SQLite 事务，开始提交后暂时禁用取消并说明原因；提交失败则整体回滚为零新增，重试不会生成重复的半成品项目。
- 自动备份失败不阻止日常规划，但在设置入口和数据页保留状态提示，提供“立即重试／打开备份目录／查看详情”，同一未解决原因不连续弹窗。手动备份与导出先写临时文件，完成校验后再替换目标；取消或失败会清理临时文件，不留下看似可用的半份备份。
- 恢复备份使用“验证备份／创建恢复前备份／替换数据／验证结果”四阶段进度；前两阶段可以取消且当前数据不变，开始替换后禁用取消并显示“正在完成安全替换”。任一阶段失败都优先保留或恢复原数据库；只有验证新数据成功后才重新加载界面，并汇总恢复的任务与项目数量。
- 通知权限拒绝在设置行内显示并提供“打开 Windows 设置”，不重复触发系统请求；可检测到系统勿扰时仅说明通知可能延后，不将其视为应用错误。开机自启注册失败时开关回到最后确认状态并可重试；新全局快捷键注册冲突时保留旧快捷键继续生效。系统操作和所有重试必须幂等，不因重复点击创建重复提醒、任务、备份或注册项。

## 回顾页面

- 主导航提供统一的“回顾”页面，通过顶部控件在日、周、月三个周期间切换，不拆成三个独立页面。
- 回顾无需用户手动生成，打开任意周期时根据当前本地记录实时计算；补填或修正历史后，过去周期的回顾同步更新。
- 导出图片或文件时生成固定快照，后续数据修改不会改变已经导出的版本。
- 首次从主导航进入回顾时默认显示当前周，之后记住最近使用的日／周／月周期与日期范围；从某个日期或任务记录进入时直接聚焦对应日回顾。页面信息顺序固定为成果与待续、核心图表、项目／分类下钻、可选感受与评论，不把统计卡片放在行动结果之前。
- 日回顾顶部列出完成、部分推进和待续任务，并用每项“开始完成度 → 结束完成度”的横向变化条呈现手动进度；其后使用同一时间轴叠加计划执行时段与实际执行记录，再展示实际投入、开始签到状态和本次小结。没有开启签到或没有记录时显示“未启用／未记录”，不按迟到处理。
- 周回顾以 7 根柱显示每天的今日总进度，以独立堆叠条显示实际投入的分类分布；下方列出本周项目里程碑、完成成果和待续事项。满意度显示平均值时同时显示填写次数，常见感受只按用户实际选择次数汇总，没有填写时整个主观反馈区折叠。
- 月回顾以月历热度显示每天的今日总进度，另以每周柱状图展示累计实际投入；项目列表按本月手动进度增加量显示推进较多的项目，并列出完成成果、推进较多的日期和用户评论摘录。“推进较多”只引用现有进度数据，不称为最佳状态，也不推断心理或效率。
- 日回顾优先与当日目标进度和计划时段比较；周、月默认只展示当前周期，不强制与过去竞争。工具栏可开启“与上一周期对比”，仅并列已有的今日总进度、实际投入、完成／推进任务数和已记录的准时启动数据；缺少同口径数据时显示“无可比记录”，不合成总分、连续天数或升降评价。
- 未完成内容以“待续”呈现，不使用失败或惩罚性语言；系统只汇总用户原始数据和评论，不使用 AI 推断心理状态。
- 回顾图表支持悬停或键盘聚焦查看精确数值；点击日期、分类、项目或图表数据点后，在当前页面下方或右侧展开对应任务、进度变化和本次小结。图形同时提供文字数值和列表入口，不把颜色或悬停作为读取数据的唯一方式。
- 从下钻详情返回时保留原周期、筛选条件和滚动位置，避免用户重新寻找刚才查看的数据。
- 周期完全没有计划和实际记录时不绘制全零图表，沿用“有实际推进后，这里会出现回顾／前往今日”的空状态；存在计划但没有实际记录时仍显示计划时间轴与待续任务，实际字段标为“未记录”，不把缺失记录换算成 0% 或失败。
- 第一版导出提供 `PNG 摘要`和`CSV 明细`：PNG 采用纵向布局，包含周期与生成时间、成果／待续摘要、该周期核心图表、里程碑和推进项目；CSV 按任务或执行记录逐行包含日期、分类／项目、进度变化、实际投入和记录状态，并注明筛选条件与时区。导出面板明确提示文件含任务／项目名称；满意度、感受标签和自由评论默认不导出，需单独勾选。所有导出仅写入用户选择的本地路径，不上传网络。
