# 阶段 3：完整日历体验

本规格把 `docs/design/UI-SPEC.md` 中"日历视图""拖拽排程"与"今日页"相关的完整体验目标，整理为阶段 3 的正式工作范围。阶段 3 不改变领域模型，也不引入新的持久化对象，只把阶段 2 已有的日历最小实现升级为规格描述的完整交互。

## Problem Statement

阶段 2 的日历只满足"可拖入、可移动、可缩放、可撤销"的最低验收要求，但在真实使用中体验明显不足：

- 默认时段从 19:00 开始时，上午区域几乎全空，纵向比例失衡，用户要滚动才能看到大部分时间。
- 默认时段标签的位置不固定，容易贴到格子底部，像贴错位置。
- 短时段（如 20 分钟）卡片被挤压到十几像素高，时间、标题、进度被截断。
- 没有"折叠非默认时段"机制，全天时间轴被低相关时段拉长。
- 拖拽落点没有实时预览，松手前不知道会放到几点。
- 没有插入并后移、并行重叠、空白框选等排程动作。
- 只有日／周两种视图，缺少月视图与连续日视图。
- 时间轴不能缩放，卡片内容也不能根据可用高度自适应。
- 当前时间线、当前安排高亮、"待回顾"状态等今日感知缺失。

这些问题不影响数据正确性，但会让用户不愿把日历当作日常排程入口。

## Solution

阶段 3 把日历升级为规格描述的完整体验，分四个模块交付：

1. **三视图与连续时间轴**：在现有日／周视图之上新增月视图，日视图改为可跨越日期边界的连续时间轴，周视图以周一为起点并固定吸顶日期头。
2. **默认时段折叠与临时展开**：日视图引入"默认时段"与"全天"两种显示模式，折叠非默认时段为带数量提示的间隔条，并在拖拽悬停、当前时间落入、跳转目标命中时临时展开。
3. **缩放与卡片自适应**：时间轴支持 Ctrl+滚轮缩放与三档可见入口，执行卡片根据可用高度逐级增减信息量。
4. **完整拖拽排程**：实时预览、插入并后移、中央重叠、并行并排与"另外 N 项"折叠、空白点击小气泡与纵向框选。

阶段 3 不改变任务、执行时段、时间块、重复习惯等任何持久化结构，所有体验改进都基于现有数据与既有命令通道。`UI-SPEC.md` 中的项目截止日期与项目里程碑仍是长期交互目标，但它们属于尚未建立的核心领域事实，不在阶段 3 内临时存入设置或从子任务截止日期推导；对应数据模型与日历标记转入 M7。

## Milestones and Sequencing

阶段 3 拆分为六个可独立验收的里程碑，按"基础设施 → 内容呈现 → 排程动作"的依赖顺序排列。每个里程碑都可在完成时单独打包验证；后置里程碑依赖前置里程碑的渲染与状态基础，但不依赖其排程动作。

### M1 时间轴骨架与三视图

**目标**：把日历从"按按钮切单日"升级为可跨日期边界连续滚动的时间轴，并补齐周视图吸顶日期头、月视图固定六行网格与视图切换的状态保留。这是后续所有体验的基础。

**范围**：
- 3.1 日历三视图与连续时间轴的全部验收标准。
- 日视图连续滚动越过 00:00／24:00 边界时无缝进入相邻日期；固定日期标题与常驻"回到今天"按钮。
- 周视图以周一为起点，日期头吸顶；今天以"今天"文字与描边标明；单击日期头进入该日连续日视图。
- 月视图固定六行日期网格，周一为每行起点，相邻月份日期弱化保留，切月网格高度不跳动。
- 视图切换保留各自最近一次的锚点日期与缩放程度。

**依赖**：无。直接基于阶段 2 现有数据与渲染。

**验收**：可在日视图连续滚动跨越午夜、周视图单击日期头进入日视图、月视图切月不跳动，且切换视图后回到原视图时锚点与缩放保留。

### M2 状态感知与计划/实际叠加

**目标**：让日历"知道现在在哪"，显示当前时间线、当前安排高亮和"待回顾"状态，并支持计划与实际叠加的只读呈现。这是最直接的体验改善，不依赖排程动作。

**范围**：
- 3.6 当前时间线与状态感知的全部验收标准。
- 3.7 计划与实际叠加的全部验收标准。
- 今天时间轴显示当前时间线与时间标签；已过去区域极淡背景；滚离当前时间后显示"回到现在"按钮。
- 当前时间落入执行时段时卡片高亮边框与轻微光晕；细时间条显示本时段已过去多久，与较粗的手动任务进度条明确分开。
- 已结束但任务未完成的执行时段进入"待回顾"，提供"更新进度""继续安排""本次未推进"三操作；未获用户确认前不自动判为未执行。
- 工具栏"显示实际记录"开关；原执行时段淡色虚线轮廓，实际执行记录实色层从实际开始延伸到实际结束或当前时间。
- 状态区分同时使用边框、文字或图标，不只依赖颜色。

**依赖**：M1（时间轴与视图切换）。

**验收**：今天视图可见当前时间线与已过去区域；当前安排卡片有高亮与光晕；已结束未完成任务显示"待回顾"及三操作；开启"显示实际记录"后实际执行如实叠加，提前/延后/重叠只呈现不修改原计划。

### M3 缩放与卡片自适应

**目标**：解决短时段卡片被挤压、信息不可读的问题，让时间轴可缩放、卡片信息量随可用高度自适应。这是让日历"可读"的关键，且不依赖排程动作。

**范围**：
- 3.5 缩放与卡片自适应的全部验收标准。
- 普通滚轮浏览时间轴；`Ctrl + 滚轮`或触控板捏合缩放，以指针所在时间为锚点。
- 工具栏"紧凑／标准／详细"三档可见缩放入口；每种视图分别持久化最近缩放程度。
- 卡片可用高度对应少于约 30 分钟时只显示任务标题、分类色条和必要状态图标。
- 约 30–59 分钟增加开始／结束时间与细进度条。
- 约 60 分钟以上再显示项目、进度百分比和主要操作。
- 缩放只改变视觉密度与卡片信息量，不改变执行时段真实的开始、结束或任务数据。

**依赖**：M1（时间轴）；建议在 M2（状态感知）之后，以便自适应规则能同时处理状态标记。

**验收**：`Ctrl + 滚轮`以指针时间为锚点缩放；三档入口可见且各视图分别记忆；短时段卡片只显示标题与色条，中时段增加时间与进度条，长时段显示完整信息；缩放不改变任何执行时段数据。

### M4 默认时段折叠与临时展开

**目标**：把日视图从"全天平铺"改为"默认时段优先"，折叠非默认时段为带数量提示的间隔条，并在拖拽悬停、当前时间落入、跳转目标命中时临时展开。这是让日视图比例不再失衡的核心，也直接影响排程体验。

**范围**：
- 3.2 默认时段折叠与临时展开的全部验收标准。
- 日视图"默认时段"与"全天"两种显示模式；用户可设默认打开模式，界面记住最近一次选择。
- 折叠条始终显示起止与安排数量，例如"10:00–18:00 · 2 项安排"；点击切换临时展开，再次点击收起。
- 拖拽悬停折叠条约半秒自动展开；拖离未提交恢复原状；放置成功后保留临时展开。
- 当前时间在折叠区时自动展开约两小时窗口；其余非默认时段继续折叠。
- 从外部跳转到折叠区内安排时自动临时展开并高亮目标卡片。
- 临时展开状态只属于当前浏览过程，不修改用户配置的默认时段。

**依赖**：M1（时间轴）、M3（缩放，确保折叠展开后比例可控）。

**验收**：默认时段模式下非默认时段折叠为带数量提示的间隔条；拖拽悬停半秒展开、拖离恢复、放置成功保留；当前时间在折叠区时自动展开两小时窗口；外部跳转命中折叠区内安排时自动展开并高亮。

### M5 完整拖拽排程

**目标**：把拖拽从"松手才知道放哪"升级为带实时预览、插入并后移、中央重叠、并行并排与空白框选的完整排程动作。这是阶段 3 体验的核心，也最复杂，放在基础设施稳定后开工。

**范围**：
- 3.8 完整拖拽排程的全部验收标准。
- 拖拽期间持续显示精确时间预览与可放置区域；磁铁按钮显示当前吸附状态（如"吸附 15 分钟"）；关闭后自由拖动；`Alt` 临时反转当前吸附状态。
- 边缘插入显示插入线并执行"插入并后移"，目标之后任务平滑让位；松手才提交，拖出有效区域复原。
- 中央悬停约半秒触发"同时安排"聚拢动画；松手才创建重叠时段。
- 并行 2–3 项并排等宽显示；4 项以上显示前两项加"另外 N 项"汇总卡，点击原位展开临时列表。
- 空白时段悬停显示淡化 `＋` 与时间；单击展开小气泡提供"新建任务""从任务池安排""时间块"；纵向拖动框选后打开同一小气泡并预填时段；`Esc` 或点击外部取消。
- 插入与重叠使用不同落点、动画和文字反馈；重叠任务并排或错层显示并标明同时安排数量，不合并数据或改变任务所属结构。

**依赖**：M1（时间轴）、M4（折叠展开，确保拖入折叠区时能展开放置）、M3（缩放，确保预览位置精度）。

**验收**：拖拽期间持续显示精确时间预览与可放置区域；磁铁按钮显示吸附状态且 `Alt` 临时反转；边缘插入显示插入线并让位、松手才提交、拖出复原；中央悬停半秒聚拢、松手才创建重叠；并行 2–3 项并排、4 项以上显示"另外 N 项"汇总卡；空白悬停显示 `＋` 与时间、单击或框选打开小气泡提供三入口。

### M6 周视图全天区域、月视图摘要与键盘导航

**目标**：补齐周视图全天区域与列宽自适应、月视图摘要与详情、周/月视图键盘导航。这些是"完整体验"的最后一块拼图，不阻塞核心排程，但影响整体可用性。

**范围**：
- 3.3 周视图全天区域与列宽自适应的全部验收标准。
- 3.4 月视图摘要与详情的全部验收标准。
- 3.9 键盘导航的全部验收标准。
- 周视图顶部可折叠全天区域，承载当前领域已有的任务截止旗帜，默认两行，超出用"另外 N 项"原位展开；点击标记在右侧打开对应详情。项目截止旗帜与里程碑菱形待 M7 建立核心数据后接入同一标记区域。
- 日列变窄时按标题、时间、状态、进度、项目顺序逐级隐藏；中央区域不足时优先收起右侧面板和左侧导航，不把七列压缩到不可读。
- 月日期格按截止任务、完成、推进与未推进摘要顺序展示最多三条，其余合并为"另外 N 项"；点击"另外 N 项"或日期格空白选中日期，右侧显示当天完整列表，不使用弹窗。
- 单击任务截止标记直接在右侧打开对应详情，同时保留该日期选中描边；右侧摘要提供显式"打开日视图"。项目截止与里程碑标记待 M7 接入。
- 周视图日期头左右方向键移动；时间网格方向键移动到相邻日期或吸附时间；`Page Up`／`Page Down` 切换前后周；`Enter` 打开详情或在空白时间创建小气泡。
- 月视图方向键按日移动焦点，跨行与跨月连续；`Page Up`／`Page Down` 切月；`Home`／`End` 移到当前周首末日；`Enter` 选中日期并打开右侧摘要。
- 焦点移动不等同于创建或选择数据；切换视图或从详情返回时保留所选日期；焦点与选中状态使用不同样式。

**依赖**：M1（三视图）、M2（状态感知，月视图摘要需要完成/推进数据）、M5（拖拽，确保键盘 `Enter` 在空白时间创建小气泡的入口已就绪）。

**验收**：周视图全天区域承载已有任务截止标记且超出时"另外 N 项"展开；日列变窄时按序隐藏低优先信息；月视图日期格只展示摘要且点击日期右侧显示完整列表；周/月视图方向键、`Page Up`／`Page Down`、`Home`／`End`、`Enter` 语义正确，焦点与选中状态可区分。项目截止与里程碑标记不作为 M6 验收条件。

## Milestone Summary

| 里程碑 | 模块覆盖 | 依赖 | 核心交付 |
|---|---|---|---|
| M1 | 3.1 | 无 | 连续时间轴、三视图、状态保留 |
| M2 | 3.6、3.7 | M1 | 当前时间线、待回顾、计划/实际叠加 |
| M3 | 3.5 | M1，建议 M2 后 | 缩放、卡片信息量自适应 |
| M4 | 3.2 | M1、M3 | 默认时段折叠、临时展开 |
| M5 | 3.8 | M1、M3、M4 | 实时预览、插入后移、重叠、并行、框选 |
| M6 | 3.3、3.4、3.9 | M1、M2、M5 | 全天区域、月摘要、键盘导航 |

## Suggested Execution Order

按依赖与价值排序，建议执行顺序为 **M1 → M2 → M3 → M4 → M5 → M6**。每个里程碑完成后可单独打包验证，不必等阶段 3 全部完成。

- M1 是所有后续工作的基础，必须最先。
- M2 不依赖排程动作且体验改善最直接，紧随 M1。
- M3 让卡片可读，是 M4 折叠展开后比例可控的前提，建议在 M2 之后。
- M4 直接解决"时间轴比例失衡"的核心抱怨，依赖 M1 与 M3。
- M5 是阶段 3 最复杂、最高风险的部分，放在基础设施稳定后开工，依赖 M1、M3、M4。
- M6 是完整体验的最后拼图，不阻塞核心排程，可最后补齐。

若实施中资源紧张，M5 与 M6 可考虑拆分内部子任务并行推进，但 M5 的拖拽排程动作之间耦合较紧，不建议跨里程碑拆分。

## User Stories and Acceptance Criteria

### 3.1 日历三视图与连续时间轴

- **作为用户**，我希望日历默认进入周视图，以便观察一周容量并在日期之间拖拽任务。
- **作为用户**，我希望日视图使用可跨越日期边界的连续时间轴，向上进入前一天、向下进入下一天，并有固定日期标题、日期分隔线和"回到今天"按钮防止迷失。
- **作为用户**，我希望月视图用于回顾已完成事项并显示截止日等重要日期，不在日期格里做精细小时排程。
- **作为用户**，我希望周以周一开始，今天同时以"今天"文字和描边标明；单击周视图日期头进入该日的连续日视图。

验收标准：

- 日历默认视图为周视图；首次进入或无记忆时落在当前周。
- 日视图滚动越过 00:00／24:00 边界时无缝进入相邻日期，顶部固定显示当前日期标题，并提供常驻"回到今天"按钮。
- 月视图使用固定六行日期网格，周一为每行起点，相邻月份日期以弱化样式保留，切月时网格高度不跳动。
- 切换视图后保留各自最近一次的锚点日期与缩放程度。
- 视图切换不产生新的数据库写入，只读取现有任务、执行时段、时间块与记录。

### 3.2 默认时段折叠与临时展开

- **作为用户**，我希望日视图在"默认时段"模式下只展开我配置的时段，把其他时间折叠为带任务数量提示的间隔条，避免时间轴被低相关时段拉长。
- **作为用户**，我希望折叠条始终显示起止时间与其中的安排数量，例如"10:00–18:00 · 2 项安排"，点击可临时展开或收起。
- **作为用户**，当我拖动任务悬停在折叠条约半秒时，希望对应时段自动展开以便精确放置；拖离且未提交时恢复原状，成功放置后保留临时展开以展示结果。
- **作为用户**，当当前时间落入折叠区时，希望日视图自动展开当前时间附近约两小时的窗口，确保当前时间线与当前安排可见。
- **作为用户**，从通知、搜索结果或其他页面跳转到折叠区内的安排时，希望自动临时展开目标时段并高亮对应卡片。

验收标准：

- 日视图提供"默认时段"与"全天"两种显示模式；用户可设置默认打开模式，界面也记住最近一次选择。
- 折叠条始终显示起止与安排数量；点击切换临时展开，再次点击收起。
- 拖拽悬停折叠条约半秒自动展开；拖离未提交恢复原状；放置成功后保留临时展开。
- 当前时间在折叠区时自动展开约两小时窗口；其余非默认时段继续折叠。
- 从外部跳转到折叠区内安排时自动临时展开并高亮目标卡片。
- 临时展开状态只属于当前浏览过程，不修改用户配置的默认时段。

### 3.3 周视图全天区域与列宽自适应

- **作为用户**，我希望周视图顶部有可折叠的全天区域，承载当前已有任务的不占时长截止旗帜，不把它们转成执行时段；项目截止旗帜和里程碑菱形在 M7 建立对应领域事实后接入。
- **作为用户**，当周视图日列变窄时，希望按标题、时间、状态、进度、项目的顺序逐级隐藏低优先信息，始终保留标题和非纯颜色状态。
- **作为用户**，我希望悬停、键盘聚焦或选中卡片后通过邻近操作条与右侧详情获得完整内容。

验收标准：

- 周视图顶部全天区域默认显示两行，超出后用"另外 N 项"原位展开列表；点击任务截止标记在右侧打开对应任务详情。
- 日列变窄时按既定顺序逐级隐藏信息；中央区域不足时优先收起右侧面板和左侧导航，不把七列压缩到不可读宽度。
- 全天区域只承载标记，不创建执行时段，不改变任务所属结构。

### 3.4 月视图摘要与详情

- **作为用户**，我希望月视图日期格只展示完成、推进和未推进数量，以及今日总进度的轻量摘要，不在格内做精细排程。
- **作为用户**，我希望截止事项使用有紧迫程度区分的标记；点击日期后在右侧展示当天完整任务列表与进度变化，不使用弹窗。

验收标准：

- 月日期格按截止任务、完成、推进与未推进摘要的顺序展示最多三条重要信息，其余合并为"另外 N 项"。
- 点击"另外 N 项"或日期格空白选中日期，右侧显示当天完整列表，不使用弹窗，不改变当前月份和滚动位置。
- 单击具体任务截止标记直接在右侧打开对应详情，同时保留该日期选中描边；右侧摘要提供显式"打开日视图"。
- 第一版月视图只支持单日选择，不提供拖拽范围选择或日期格内精细调整时长。

### 3.5 缩放与卡片自适应

- **作为用户**，我希望普通滚轮浏览时间轴，`Ctrl + 滚轮`或触控板捏合调整纵向时间比例，并保持指针所在时间为缩放锚点。
- **作为用户**，我希望工具栏提供"紧凑／标准／详细"三个可见缩放入口，每种视图分别记住上次缩放程度。
- **作为用户**，我希望执行卡片根据当前缩放和可用高度自动调整信息量，而不是用固定内容挤压短时段。

验收标准：

- `Ctrl + 滚轮`或触控板捏合缩放，以指针所在时间为锚点；普通滚轮只浏览。
- 工具栏三档缩放入口可见；每种视图分别持久化最近缩放程度。
- 卡片可用高度对应少于约 30 分钟时只显示任务标题、分类色条和必要状态图标；约 30–59 分钟增加开始／结束时间与细进度条；约 60 分钟以上再显示项目、进度百分比和主要操作。
- 缩放只改变视觉密度与卡片信息量，不改变执行时段真实的开始、结束或任务数据。

### 3.6 当前时间线与状态感知

- **作为用户**，我希望今天的时间轴显示带时间标签的当前时间线，并以极淡背景区分已过去区域。
- **作为用户**，当当前时间落入某个执行时段时，希望任务卡以高亮边框和轻微光晕标记"当前安排"，但不自动声称我正在执行。
- **作为用户**，已结束但任务未完成的执行时段进入"待回顾"，显示时段已结束和当前手动进度，提供"更新进度""继续安排"和"本次未推进"。

验收标准：

- 今天时间轴显示当前时间线与时间标签；已过去区域用极淡背景区分；滚离当前时间后显示带方向提示的"回到现在"按钮。
- 当前时间落入执行时段时卡片高亮边框与轻微光晕；卡片用细时间条显示本时段已过去多久，与较粗的手动任务进度条明确分开。
- 已结束但任务未完成的执行时段进入"待回顾"，显示结束状态与当前进度，提供三个操作；未获用户确认前不自动判为未执行。
- 状态区分同时使用边框、文字或图标，不只依赖颜色；临近截止只在卡片上显示小旗帜，完整截止日期在悬停、选中或详情中查看。

### 3.7 计划与实际叠加

- **作为用户**，我希望日历可叠加显示计划与实际：原执行时段用淡色虚线轮廓，实际执行记录用实色层，从实际开始延伸到实际结束或当前时间。

验收标准：

- 工具栏提供"显示实际记录"开关，并支持在自定义界面中隐藏。
- 提前、延后或实际重叠只如实呈现，不反向移动原计划或自动推开其他任务。

### 3.8 完整拖拽排程

- **作为用户**，我希望从任务池拖入日历时默认按 15 分钟吸附，并实时预览开始时间、结束时间和可放置区域。
- **作为用户**，我希望工具栏有可见的磁铁按钮显示"吸附 15 分钟"等当前状态；关闭后进入自由拖动；拖拽期间按住 `Alt` 临时反转当前吸附状态。
- **作为用户**，我希望拖到已有任务上方或下方时显示插入线并默认"插入并后移"，目标之后的任务像手机图标让位一样平滑移动，松手才提交，拖出有效区域全部复原。
- **作为用户**，我希望在已有任务中央悬停约半秒时两张卡片吸附聚拢并显示"同时安排"，松手才创建重叠时段。
- **作为用户**，我希望同一时间并行 2–3 项时卡片并排等宽显示；达到 4 项以上时显示前两项加"另外 N 项"汇总卡，点击原位展开临时列表。
- **作为用户**，我希望鼠标移入空白时段时显示淡化的 `＋` 与对应时间，单击展开小气泡提供"新建任务""从任务池安排""时间块"，不会仅因点中空白就直接创建数据。
- **作为用户**，我希望在空白时段纵向拖动框选开始与结束时间，松手打开同一个锚定小气泡并预填所选时段。

验收标准：

- 拖拽期间持续显示精确时间预览与可放置区域；吸附状态由磁铁按钮控制，`Alt` 临时反转。
- 边缘插入显示插入线并执行"插入并后移"，目标之后任务平滑让位；松手才提交，拖出有效区域复原。
- 中央悬停约半秒触发"同时安排"聚拢动画；松手才创建重叠时段。
- 并行 2–3 项并排等宽显示；4 项以上显示前两项加"另外 N 项"汇总卡，点击原位展开临时列表。
- 空白时段悬停显示淡化 `＋` 与时间；单击展开小气泡提供三个入口；纵向拖动框选后打开同一小气泡并预填时段，`Esc` 或点击外部取消。
- 插入与重叠使用不同落点、动画和文字反馈；重叠任务并排或错层显示并标明同时安排数量，不合并数据或改变任务所属结构。

### 3.9 键盘导航

- **作为用户**，我希望在周视图用方向键在日期头与时间网格间移动，`Page Up`／`Page Down` 切换前后周，`Enter` 打开详情或在空白时间创建小气泡。
- **作为用户**，我希望在月视图用方向键按日移动焦点，`Page Up`／`Page Down` 切月，`Home`／`End` 移到当前周首末日，`Enter` 选中日期并打开右侧摘要。

验收标准：

- 周视图日期头之间用左右方向键移动；时间网格中方向键移动到相邻日期或吸附时间；`Page Up`／`Page Down` 切换前后周；`Enter` 打开详情或在空白时间创建小气泡。
- 月视图方向键按日移动焦点，跨行与跨月连续移动；`Page Up`／`Page Down` 切月；`Home`／`End` 移到当前周首末日；`Enter` 选中日期并打开右侧摘要。
- 焦点移动不等同于创建或选择数据；切换视图或从详情返回时保留所选日期；焦点与选中状态使用不同样式。

## Data and Safety Decisions

- 阶段 3 不新增 SQLite 表、不新增字段、不新增迁移；所有体验改进都基于阶段 2 已有的任务、执行时段、时间块、重复习惯、执行记录与进度事件。
- 项目截止日期与项目里程碑是核心领域事实，不能写入 Tauri Store、由子任务截止日期推导或仅存在于前端内存；其 SQLite 模型、迁移、命令、备份兼容与日历标记统一转入 M7。
- 视图模式、缩放程度、显示模式等纯界面偏好可作为设置项持久化到 Tauri Store，但不进入 SQLite 核心数据。
- 插入并后移、并行重叠等排程动作最终仍通过既有的 `updateExecutionSession`／`createExecutionSession` 通道原子写入；前端预览只存在于内存，松手才提交，拖出有效区域全部复原。
- 计划与实际叠加只读取现有执行记录，不反向修改原计划时段；"显示实际记录"开关状态作为偏好持久化。
- 所有核心写操作继续经过 Tauri 后台串行队列，并在成功后刷新当日备份。

## Testing Decisions

- 时间轴渲染接缝覆盖连续日期边界、折叠条数量提示、临时展开与恢复、当前时间窗口展开。
- 缩放接缝覆盖锚点保持、三档入口持久化、卡片信息量逐级增减、真实数据不变。
- 拖拽接缝覆盖吸附预览、插入并后移的让位与复原、中央重叠聚拢、并行并排与"另外 N 项"折叠、空白小气泡与框选预填。
- 状态感知接缝覆盖当前时间线、当前安排高亮、"待回顾"三操作、计划与实际叠加只读性。
- 键盘接缝覆盖周／月视图方向键、`Page Up`／`Page Down`、`Home`／`End`、`Enter` 语义与焦点选中区分。
- 端到端覆盖从任务池拖入周视图、跨日连续滚动放置、月视图选中日期打开详情、并行重叠创建与展开。

## Out of Scope

- 不新增领域对象或 SQLite 迁移；重复习惯、B 站导入、自动排程 Lite 等阶段 2 能力保持不变。
- 不实现项目截止日期或项目里程碑；M6 只为现有任务截止日期提供全天区和月视图标记。二者将在 M7 作为核心领域事实实现后复用现有日历标记接缝。
- 不做 AI 规划、复杂重复规则、独立截止任务页或完整日／周／月回顾；这些仍属更后续阶段。
- 月视图第一版只支持单日选择，不提供拖拽范围选择或日期格内精细调整时长。
- 并行直接展示上限固定为 3 项，不提供超过 3 项的并排压缩方案。
- 不改变通知、托盘、备份恢复等原生层行为。

## Further Notes

- 本规格全部目标来自 `docs/design/UI-SPEC.md` 的"日历视图""拖拽排程"与"今日页"章节，未引入规格外的新交互；若 UI-SPEC 后续调整，以 UI-SPEC 为准。
- 阶段 3 与阶段 2 的衔接：日历现有的拖入、移动、缩放、撤销、精确时间编辑、吸附关闭等能力作为阶段 3 的基线，阶段 3 在其上叠加预览、折叠、缩放自适应与完整排程动作，不重写既有命令通道。
- 阶段 3 完成后，日历的已知边界将收敛为：连续日期虚拟滚动仍按三日缓冲＋边界平移实现；项目截止与里程碑标记等待 M7 的核心数据；其余本规格范围内目标应全部达成。
- 实施前应先与设计确认缩放档位的像素映射、折叠条展开动画时长、插入让位动画曲线等具体参数，本规格只锁定行为语义，不锁定视觉参数。
