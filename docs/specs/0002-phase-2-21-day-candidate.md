# Daymark 阶段 2：正式 21 天候选版

## Problem Statement

阶段 1 已验证任务可以可靠地被记录、手动安排、执行和恢复，但用户仍需自己从任务池中选择下一项、寻找空档，并在错过开始后重新完成整套安排。正式 21 天体验需要验证 Daymark 是否真的减少选择压力、帮助开始，并让一次错过容易恢复，而不是只提供一套可靠但高维护成本的记录工具。

## Solution

阶段 2 在现有事实模型上加入六个纵向能力：自动排程 Lite、轻量时间块、基础重复习惯、错过后的挽救提示、简单最近 7 天回顾，以及 Beta 版 B 站链接导入。所有建议使用确定性规则，核心写入仍由用户确认；计划、实际执行和完成度继续分离；错过与待续使用中性语言并保留历史。

## User Stories and Acceptance Criteria

### 自动排程 Lite

1. 用户可以从任务池主动打开自动排程，看到未来 7 天默认时段内可安排的任务和可用容量。
2. 排程只追加到空档，不移动或覆盖既有执行时段、时间块，也不超出适用的默认时段。
3. 候选按截止日期、优先级和任务池顺序确定性排序；任务使用自己的单次投入时长，未设置时使用全局默认值。
4. 短于全局最低有效时长的空档不参与；任务的"单次投入时长"只是自动排程优先尝试的目标长度，不是不可拆分的硬约束——当空档达到最低有效时长但短于目标时，任务仍可被安排为较短的时段，剩余部分以后继续。
5. 用户先选择任务并查看草案；只有确认后才批量写入执行时段，整批写入原子完成并可一次撤销。

### 轻量时间块

1. 用户可以在日历创建和删除只含标题、日期与起止时间的时间块。
2. 时间块与任务执行时段视觉和数据上保持分离，不进入任务池、没有进度，也不计入回顾的任务达成数据。
3. 自动排程把时间块视为不可用容量，不生成重叠草案。

### 基础重复习惯

1. 用户可以创建每天、工作日或每周选择日期的重复习惯，并设置单次投入时长和可选固定开始时间。
2. 习惯是一个持续定义；每个发生日期拥有独立状态，不为每天复制普通任务。
3. 默认未完成处理是不累积：过去的发生事实保留，但不会自动复制成多份今日欠账。
4. 用户可以安排今天的发生项或跳过本次；安排后使用既有开始／结束与执行记录闭环。
5. 自动排程可以把未安排的习惯发生项作为候选，但不会为同一习惯日期创建重复时段。

### 错过后的挽救提示

1. 只有开启开始签到和挽救提示时，执行时段超过开始时间与宽限期且尚未开始，今日页才显示一次非模态提示。
2. 提示提供“现在开始”“延后 10 分钟”“重新选择时间”和“本次跳过”；跳过不完成或删除任务。
3. 提示显示事实持久化，同一执行时段不连续催促；所有文案面向下一步，不使用失败、落后或羞辱性措辞。

### 简单最近 7 天回顾

1. 主导航提供“7 天回顾”，实时汇总今天及之前共 7 个本地日期。
2. 回顾先显示完成／推进成果和待续，再显示每天的实际投入、进度增加、未执行／跳过数量。
3. 没有记录时显示安静的空状态；缺少签到记录不换算成失败或 0 分，不生成总分、连续天数或评价。

### B 站链接导入 Beta

1. 用户可以粘贴包含 BV 号的 B 站普通视频链接，由桌面原生层读取公开视频和分 P 元数据；不使用 AI、不下载视频。
2. 导入前展示可编辑、可取消选择的分 P 预览；确认后以一个事务创建普通项目及有序任务。
3. 每个分 P 分别保存媒体时长和指向对应 `?p=序号` 的来源链接；媒体时长不自动声称为实际投入。
4. 读取失败时保留原链接并给出可重试错误，文本课程导入仍可独立使用。
5. Beta 不包含内嵌播放器、观看跟踪、大规模元数据处理或复杂重复课程合并。

## Data and Safety Decisions

- 新领域数据继续进入 SQLite，并通过顺序迁移从 schema v4 升级；旧任务、计划、实际记录和时间块不得被改写。
- 重复习惯定义及显式发生状态存入 SQLite；用于执行闭环的内部关联任务不显示为普通任务池条目。
- B 站来源标识、分 P 链接和媒体时长作为任务元数据保存；网络读取本身不写数据库。
- 自动排程草案只存在于前端内存；确认后的批量执行时段才进入 SQLite。
- 新核心写操作继续经过 Tauri 后台串行队列，并在成功后刷新当日备份。

## Testing Decisions

- 领域接缝覆盖 v4→新版本迁移、时间块写入／删除、重复习惯事务、习惯发生状态、批量排程原子性和旧事实保留。
- 确定性算法接缝覆盖空档计算、时间块排除、最低有效时长、排序、部分安排（短于目标但不短于最低值，且不自动补排）和习惯去重。
- UI 用户闭环覆盖排程预览后应用、时间块创建、习惯创建／安排、四种挽救动作、7 天回顾以及 B 站预览导入。
- B 站网络请求在测试中使用固定响应，不依赖在线服务。

## Out of Scope

- 自动移动既有安排、AI 规划、截止风险压排、级联顺延和后台无确认排程。
- 复杂月度重复、结束次数、未来规则批量重写、习惯与任意长期任务的高级关联，以及多份欠账。
- 完整日／周／月回顾、周期竞赛、评分、PNG／CSV 导出和高级统计。
- B 站登录态读取、内嵌播放器、观看进度、自动完成、重复课程合并和非普通视频类型。
